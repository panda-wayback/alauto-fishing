# AI.md 规则

## 必须

1. 需被定位的代码目录各一份 `AI.md`。
2. 读代码前：根全树索引直达叶子；全树仅「路径 + 一句话」；契约在叶子。
3. 新鲜度双信号：
   - 工作区是否改过该目录（`git status` / `diff`）
   - `git log -1 --format=%ct` 比较 AI.md 与代码；代码更晚 = 落后  
   禁止用 `find -newer`。
4. 无漂移 → 信 AI.md，禁止再遍历；有漂移 → 只复查契约相关文件。
5. 先改代码并检查通过 → 再更新 AI.md。
6. 契约变更必须同步相关 AI.md；新建目录补叶子 + 根全树一行。
7. AI.md 与代码一并提交。与项目架构/docs 冲突时以架构与 docs 为准，并改 AI.md。

## 内容

根：一句话；可选短不变量；全树索引；验证命令。  
叶子：职责；目录清单；对外契约（可调用符号/入口）；约束。  
一屏左右；父级禁止重复子级细节；更新叶子后须回头删父级已下沉的重复句。

## 护栏（推荐）

测试应失败于：有 AI.md 未进全树；全树指向不存在目录；AI.md 列出的文件/子 AI.md 不存在。

## 禁止

1. 新鲜仍全量遍历。  
2. 改契约不更新 AI.md。  
3. 在 AI.md 写产品方案或长文。
