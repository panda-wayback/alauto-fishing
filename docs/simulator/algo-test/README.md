# 算法测试分包

## 目标

把拉鱼模拟器拆成可无头调用的包结构，方便接入并批量测试自动拉鱼算法；人机窗口仍可用。

## 要实现的

- `src/sim/`：纯逻辑（物理、难度、参数、观测/步进 API）；不依赖 pygame。
- 算法只通过固定观测与「是否按住」动作与模拟器交互，**测策略不点真鼠标**。
- 鱼漂位置映射为 **绿区内 0～100**（左绿缘=0，右绿缘=100；与「全长条」区分）：  
  `pos = (bobber_x - safe_left) / (safe_right - safe_left) * 100`（夹紧到 0～100）。
- **当前策略**：
  - `pos < 50` → 按住（点击）
  - `pos > 90` → 松开
  - 50～90 之间保持当前按住状态
- **切换约束**（按住↔松开）：两次切换至少间隔 **0.2s**，再加约 **100ms** 随机（实现为 `0.2 + U(0, 0.1)` 秒）。
- `src/algo/`：策略接口 + 无头跑局 + 上述策略实现。
- `src/ui/`：仅拼画面；根目录 `main.py` 为人机薄入口。
- 不做：真实游戏挂机、屏幕识图（真机执行见 `docs/autofish/act/`）。
