# 算法测试

## 目标
让拉鱼算法不开窗口、不点真鼠标，直接在模拟器上批量跑局并得到统计结果。

## 需求
- 算法只通过固定的观测快照与「是否按住」动作与模拟器交互。
- 观测中的鱼漂位置以绿区为基准取 0～100：左绿缘为 0，右绿缘为 100，超出时夹紧。
- 提供阈值策略：位置小于 50 时按住，大于 90 时松开，50～90 之间保持当前状态。
- 阈值策略两次切换（按住与松开互换）之间至少间隔 0.2 秒，再加 0～0.1 秒随机。
- 提供批量跑局入口（`make algo`），输出胜负等统计。
- 人机窗口照常可用。

## 方案
- 落点：`src/sim`（[接口](../../../src/sim/interface.yaml)），提供观测快照与步进。
- 落点：`src/algo`（[接口](../../../src/algo/interface.yaml)），策略接口、阈值策略与无头批量跑局。
- 取舍：自建观测/动作接口，不经截图与鼠标，理由是测策略要快且可重复。

## 不做
- 真实游戏挂机与屏幕识图；真机执行见 [真机自动拉鱼](../../autofish/README.md)。
