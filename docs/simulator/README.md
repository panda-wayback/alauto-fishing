# Albion 拉鱼模拟器

## 目标

桌面窗口复刻 Albion Online **拉鱼小游戏**（仅拉鱼段）：规则与手感对齐官方，界面来自截图素材，背景简化。供后续测试自动拉鱼算法；本能力不含真机挂机。

## 设计理念（对齐官方）

- **鱼漂向左** = 鱼在挣扎、往外拽（松开收线时为主）。
- **鱼漂向右** = 人在收线拉扯（按住鼠标）。
- **胜负**：在蓝条进度到头之前，鱼漂必须始终留在绿区；**碰到左右任一红区即失败**；进度到头即成功。
- **操作**：**高频短按短松**；按住→鱼漂向右，松开→向左。长按会冲右红，松太久会掉左红；不能一直按着撑完。

## 要实现的

- 玩家能开始一局拉鱼，用鼠标左键按住/松开收放线。
- 上条：固定绿安全区，两端红（含黄过渡）危险区；羽毛鱼漂左右移动。
- 按住：人向右拉（点下即有力，**按住越久向右力越猛，长按必失控撞右红**）；按住时进度涨（越靠右越快）。
- 松开：只剩鱼向左拽；松太久撞左红。
- 须靠**不断点按**把鱼漂留在绿区，直到进度到头。
- 进左右红区 → 失败；进度到头 → 成功；可重开。
- 开局可选鱼等级 **T1–T8**（越高越难）；见 [`docs/simulator/difficulty/`](difficulty/)。
- 画面：`assets/` 拼两横条；背景简化。
- 本能力不做：抛竿、等咬钩、饵/鱼竿/专精、稀有鱼单独档、真机自动拉鱼、完整场景。
- 供算法测试的分包与无头入口见 [`docs/simulator/algo-test/`](algo-test/)。
- 真机功能架构见 [`docs/autofish/`](../autofish/)（与本模拟器分离）。
