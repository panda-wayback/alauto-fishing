# 拉鱼模拟器

## 目标
在桌面窗口复刻 Albion Online 拉鱼小游戏（仅拉鱼段），规则与手感对齐官方，供人玩并测试自动拉鱼算法。

## 需求
- 玩家能开始一局拉鱼，用鼠标左键（或空格）按住收线、松开放线；可随时重开。
- 上条为固定绿色安全区，两端为红色危险区（含黄色过渡），羽毛鱼漂在条上左右移动；下条为蓝色进度条。
- 按住时人向右拉：点下即有力，按住越久向右力越猛，长按必然冲进右红区；按住时进度上涨，鱼漂越靠右涨得越快。
- 松开时只剩鱼向左拽：鱼漂向左表示鱼在挣扎，松太久会掉进左红区。
- 玩家必须高频短按短松把鱼漂留在绿区；鱼漂碰到任一红区即失败，进度到头即成功。
- 开局可选鱼等级 T1–T8，越高越难。
- 画面由 `assets/` 中的截图素材拼成两横条，背景简化。
- 算法可以不开窗口、不点真鼠标，直接在模拟器上批量跑局。

## 方案
- 子功能：[拉鱼难度](difficulty/README.md)，按 T1–T8 分档调整拉鱼难度。
- 子功能：[算法测试](algo-test/README.md)，提供无头观测/步进与阈值策略，批量测试拉鱼算法。
- 落点：`src/sim`（[接口](../../src/sim/interface.yaml)），拉鱼状态机、物理与胜负规则，不依赖 pygame。
- 落点：`src/ui`（[接口](../../src/ui/interface.yaml)），用 pygame 拼装画面与读取输入。
- 落点：根 Module（[接口](../../interface.yaml)），`main.py` / `make sim` 作为人机窗口入口。
- 取舍：逻辑与画面分包，而不是写在一个游戏循环里，理由是算法测试需要无头运行。
- 取舍：模拟器与真机自动拉鱼互不依赖，理由是两边可以独立演进与测试；真机见 [真机自动拉鱼](../autofish/README.md)。

## 不做
- 抛竿、等咬钩、饵/鱼竿/专精、稀有鱼单独档、完整场景。
- 真机挂机与屏幕识图。
