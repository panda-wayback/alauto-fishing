# 拉鱼难度

## 目标
按 Albion 鱼等级 T1–T8 分档，等级越高拉鱼越难。

## 需求
- 开局可用数字键 1～8 选择 T1–T8，默认 T4；对局套用所选档位。
- 等级升高时同时变难：
  - 鱼向左拉力更强，波动更大、更快，更难预判。
  - 进度涨得更慢，鱼漂向左时进度倒退更多。
  - 鱼漂要更靠右才涨得快，逼玩家贴近右红区操作。
  - 整体速度更快，容错更小。
- 玩家向右拉力的上限不随等级提高，高档位无法靠长按碾平。
- 绿区宽度不随等级缩小。
- 难度只影响拉鱼段。

## 方案
- 落点：`src/sim`（[接口](../../../src/sim/interface.yaml)），按档位给出相对 T4 单调加难的参数并套用到对局。
- 落点：`src/ui`（[接口](../../../src/ui/interface.yaml)），读取数字键切换档位。
- 取舍：靠鱼力、节奏与进度曲线加难，不靠缩小绿区，理由是保持与官方画面一致；参数按真机手感持续校正。

## 不做
- 稀有鱼单独档、假咬、装备加成。
