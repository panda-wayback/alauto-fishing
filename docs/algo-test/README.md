# 算法测试分包

## 目标

把拉鱼模拟器拆成可无头调用的包结构，方便接入并批量测试自动拉鱼算法；人机窗口仍可用。

## 要实现的

- `src/sim/`：纯逻辑（物理、难度、参数、观测/步进 API）；不依赖 pygame。
- 算法只通过固定观测与「是否按住」动作与模拟器交互，不直接依赖窗口层。
- `src/algo/`：策略接口 + 无头跑局/统计；本能力不含具体拉鱼策略实现。
- `src/ui/`：仅拼画面；根目录 `main.py` 为人机薄入口（`PYTHONPATH` 含 `src`）。
- 不做：真实游戏挂机、屏幕识图、具体算法策略。

## 解决步骤

1. 迁入 `src/sim/`、`src/ui/`，根目录保留 `main.py`（已完成）。
2. 提供观测快照与步进 API（已完成）。
3. 提供策略接口与无头跑局入口（已完成）。
4. 更新索引与安装说明（已完成）。
5. 包统一置于 `src/`（已完成）。
