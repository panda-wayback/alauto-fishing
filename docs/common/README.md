# 通用库

## 目标
收纳无业务、可被多个 Module 复用的基础设施。

## 需求
- 模拟器、算法与真机自动拉鱼都能复用这些能力，且无需引入对方的业务代码。
- 通用库内不出现模拟器或真机自动拉鱼的业务逻辑。

## 方案
- 子功能：[进程内订阅总线](pubsub/README.md)，进程内线程安全的发布/订阅。
- 子功能：[运行权限](permissions/README.md)，截屏、控鼠与音频捕获的权限状态与引导。
- 落点：`src/common`（[接口](../../src/common/interface.yaml)），路径、运行权限、包到期与密钥授权的通用实现；包到期与密钥激活的需求见 [真机自动拉鱼](../autofish/README.md)。
- 取舍：业务 Module 依赖通用库，通用库不依赖任何业务 Module，理由是避免循环依赖并保持可复用。
