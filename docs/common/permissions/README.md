# 运行权限（macOS / Windows）

## 目标

为真机截屏与控鼠提供**跨平台权限状态与一键引导**；不负责业务决策。

## 要实现的

- 调试壳顶栏 **「权限」** 区展示状态，并可直接发起授权/引导。
- **macOS**
  - **屏幕录制**：显示已授权/未授权；按钮打开系统设置对应页，并可触发一次轻量截屏以弹出系统授权。
  - **辅助功能**：显示已授权/未授权；按钮弹出系统授权提示，并打开辅助功能设置页。
- **Windows**
  - **截屏**：无系统隐私开关；显示探测结果（可用/异常）；可「测试截屏」。
  - **控鼠**：显示是否以管理员运行；按钮 **以管理员重新启动**（游戏提权时常用）。
- 状态可刷新；授权后用户回到壳应能看到更新（定时或点刷新）。
- 不做：五段业务、自动提权绕过 UAC 无交互、杀软白名单写入。

## 解决步骤

1. 通用库提供查询 / 打开设置 /（Windows）提权重启 API。
2. 调试壳顶栏「权限」绑定上述 API 并展示状态。
