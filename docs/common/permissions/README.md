# 运行权限（macOS / Windows）

## 目标

为真机截屏、控鼠与声音触发提供**跨平台权限状态与一键引导**；不负责业务决策。

## 要实现的

- 调试壳 **最上「权限」**（可收起）展示状态，并可直接发起授权/引导。
- **macOS**
  - **屏幕录制**：显示已授权/未授权；按钮打开系统设置对应页，并可触发一次轻量截屏以弹出系统授权。
  - **辅助功能**：显示已授权/未授权；按钮弹出系统授权提示，并打开辅助功能设置页。
  - **清理授权**：尝试 `tccutil reset`（正式/Dev Bundle）并打开设置；提示删旧条目后退出重开再授（App 内可能部分失败）。
  - **音频捕获（声音触发）**：
    - macOS 默认无法直接监听其他应用输出。
    - 需用户安装 **BlackHole / Loopback / Soundflower** 等虚拟音频驱动。
    - 推荐「音频 MIDI 设置」建**多输出设备**（扬声器 + 虚拟设备）；系统「输出」选该多输出。
    - 程序设备选虚拟设备（如 BlackHole）；系统「输入」不必强制同选。
    - **隐私与安全性 → 麦克风**：允许运行本程序的终端 / Cursor / 打包 App，否则可能一直静音。
    - 权限面板提供「声音触发」按钮打开独立设置窗口。
- **Windows**
  - **截屏**：无系统隐私开关；显示探测结果（可用/异常）；可「测试截屏」。
  - **控鼠**：显示是否以管理员运行；按钮 **以管理员重新启动**（游戏提权时常用）。
  - **音频捕获（声音触发）**：选择带 **(Loopback)** 的输出设备即可录制系统声音，无需额外驱动。
  - 不显示「清理授权」。
- 状态可刷新；授权后用户回到壳应能看到更新（定时或点刷新）。
- 不做：五段业务、自动提权绕过 UAC 无交互、杀软白名单写入、自动安装音频驱动。

## 解决步骤

1. 通用库提供查询 / 打开设置 /（Windows）提权重启 API。
2. 调试壳最上「权限」绑定上述 API 并展示状态。
3. 声音触发窗口独立管理音频设备选择、阈值与启停。
