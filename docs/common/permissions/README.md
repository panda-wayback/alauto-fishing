# 运行权限

## 目标
为真机截屏、控鼠与声音触发提供 macOS / Windows 上的权限状态展示与一键引导。

## 需求
- 调试壳最上方有可收起的「权限」区，展示各项权限状态，并可直接发起授权或引导。
- 状态可刷新；用户授权后回到调试壳，定时或点刷新即可看到更新。
- macOS：
  - 屏幕录制：显示是否已授权；按钮打开系统设置对应页，并触发一次轻量截屏以弹出系统授权。
  - 辅助功能：显示是否已授权；按钮弹出系统授权提示并打开辅助功能设置页。
  - 清理授权：尝试重置本程序的授权记录并打开设置，提示用户删掉旧条目后退出重开再授权；在 App 内可能部分失败。
  - 音频捕获：系统不能直接监听其他应用的声音，需用户自行安装 BlackHole 等虚拟音频驱动，并在「音频 MIDI 设置」建立含扬声器与虚拟设备的多输出设备作为系统输出；程序选择该虚拟设备录音，并需在「隐私与安全性 → 麦克风」中允许运行本程序的终端、Cursor 或打包 App。
- Windows：
  - 截屏：没有系统隐私开关；显示探测结果，可「测试截屏」。
  - 控鼠：显示是否以管理员运行；按钮以管理员身份重新启动（游戏提权时常用）。
  - 音频捕获：选择带 (Loopback) 的输出设备即可录制系统声音，无需额外驱动。
  - 不显示「清理授权」。
- 权限区提供「声音触发」按钮，打开独立的声音触发设置窗口（设备选择、阈值与启停属于 [真机自动拉鱼](../../autofish/README.md) 的声音开钓）。

## 方案
- 落点：`src/common`（[接口](../../../src/common/interface.yaml)），权限查询、打开系统设置与 Windows 提权重启。
- 落点：`src/tools`（[接口](../../../src/tools/interface.yaml)），权限区展示状态并绑定按钮。
- 取舍：只做查询与引导，不替用户自动授权，理由是系统授权必须由用户确认。

## 不做
- 真机五段业务决策。
- 无交互绕过 UAC 自动提权、写入杀软白名单、自动安装音频驱动。
