# 真机感知基础（截图 + 色块）

## 目标

为自动拉鱼提供感知基础：便捷标定 ROI，用与 AutoFishing 对齐的色块法得到鱼漂 **0～100**；统一窗口分区展示。不含 YOLO / 挂机点击。

## 要实现的

- **四步操作**：①截全屏 ②拖拽框选区 ③开监控 ④持续读数。
- 识别对齐 AutoFishing：**HSV 绿条 → 空洞/缺绿 → 0～100**；读数经中值平滑，短暂丢帧保持。
- 可用 **P 吸色**点绿条标定 HSV（写入 `data/hsv_zone.json`）；默认同 AF。
- 预览叠层只标边界与鱼漂，不整片染绿。
- **统一 UI 三区**：上方读数、左侧真机画面、右侧模拟器。
- 本步不做：YOLO、进度条、真机键鼠挂机。

## 操作

```text
空格  截全屏
拖拽  框选监控区域 → Enter 确认
M     开始/停止 持续监控
P     吸色：再点左侧画面绿色
C     用已有 data/screen.png 重框
Esc   取消当前模式 / 退出
```

## 解决步骤

1. 稳定截屏 + ROI（已完成）。
2. 对齐 AF：绿条 HSV + 空洞/缺绿 → 0～100（已完成）。
3. 四步状态机与统一窗口（已完成）。
4. 读数平滑 + 减弱叠层 + 吸色标定（已完成）。
