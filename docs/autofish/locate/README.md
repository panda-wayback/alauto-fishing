# 圈定范围（Locate）

## 目标

产出 mss 所需截图范围（对角点1、点2 → ROI），并持久化；可选一并持久化 **Frame 内张力条左右界**（手动标定）与识别参考图路径约定。本段不做连拍读数、点击。

## 要实现的

- 输入：屏幕画面或用户框选。
- **调试壳主路径**：手动两点框选 → **存盘** + 发布 ROI，并**同步为 mss 截图范围**；重框作兜底；**下次启动有存盘则自动载入并开监控**。
- **条界（可选）**：与 ROI 同档存盘（Frame 坐标的左右/条框）；有则识别优先用手动条界。参考图文件与 ROI 同目录约定存放，供壳右侧标记面板显示。
- **重框 / 清空 ROI**：同时清空手动条界与参考图。
- **壳上不做「找绿」入口**。
- 流水线若开启 `auto_locate`，可用固定绿 HSV 自动找条；**不得覆盖**已有手框。
- ROI 只由手框（或明确清空 / 可选 auto_locate）变更；Detect **不得**改写 ROI（可消费已存的手动条界）。
- 输出：有效 ROI 或明确无范围；可选手动条界。
- 不做：mss 连拍、读数、决策、键鼠、吸色。

## 解决步骤

1. 壳：截全屏 → 拖拽框选确认 → 存盘 + 发布 ROI；支持重框。
2. 壳右侧条界面板：参考图上标/改手动左右界并写回与 ROI 同档；首次识别成功可自动落参考图，可刷新。
3. （可选）流水线自动找绿；与壳入口分离；有手框时禁止覆盖。
