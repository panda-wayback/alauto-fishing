# 圈定范围

## 目标
让用户手框游戏中的张力条区域并存盘，作为截图范围，可选再存手动条界。

## 需求
- 用户在调试壳上两点框选 ROI，确认后立即存盘、发布，并成为截图范围；重框只改范围大小与位置。
- 下次启动若有存盘则自动载入，有 ROI 即开始截图与识别，不需要额外的监控开关。
- 无存盘时自动写入默认框：主屏居中、宽高各为屏幕的 1/4；用户手动框选的优先级高于默认框。
- 调试壳拉漂配置页提供「恢复默认框」：按当前主屏重算默认框并覆盖存盘。「更多」页的「恢复默认」也会做同样的截图恢复，见[调试壳界面](../shell/README.md)。
- 可选存手动条界（帧内张力条左右界）与标定时的帧宽，与 ROI 同档存盘；识别时手动条界优先于程序定界。
- 显示缩放变化导致帧宽与记录不同时，条界与参考图按帧宽比例换算；老存盘没有帧宽记录时按 ROI 逻辑宽处理。
- 条界参考图与 ROI 存在同一目录，供调试壳的条界标记面板显示；首次识别到鱼漂可自动落参考图。「刷新参考图」先清掉旧图、旧手动黄线与程序条界锁（避免错标记继续控拉线），再等下一次识别到鱼漂后用该帧更新，不用无漂的空图；更新后须重新标左右界。
- 重框、恢复默认框、恢复默认或清空 ROI 时，同时清空手动条界与参考图。
- ROI 只由手框、恢复默认框、恢复默认、明确清空或无存盘时的默认框改变；识别段不得改写 ROI，但可读取已存的手动条界。

## 方案
- 落点：`src/autofish/locate`，负责 ROI 与手动条界的存盘读写，接口见 [接口](../../../src/autofish/locate/interface.yaml)。
- 落点：`src/tools`，提供框选、恢复默认框与条界标记的界面，见 [调试壳界面](../shell/README.md)。
- 取舍：选手框而不是自动找绿条，因为自动找绿在复杂画面里不稳定，且会让截图范围随识别结果漂移。

## 不做
- 自动找绿、吸色定框。
- 连续截图、读数、决策与键鼠。
