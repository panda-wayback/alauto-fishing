# 圈定范围（Locate）

## 目标

产出 mss 所需截图范围（对角 **点1、点2** → ROI）。本段不做截图、读数、点击。

## 要实现的

- 输入：屏幕画面或用户框选。
- **调试壳主路径**：手动两点框选产出 ROI；**重框**作兜底。
- **壳上不做「找绿」入口**（避免误框、与监控职责混淆）。
- 流水线若开启 `auto_locate`，可用固定绿 HSV 自动找条；壳默认不启用。
- 输出：有效 ROI 或明确无范围。
- 不做：mss 连拍、读数、决策、键鼠、吸色。

## 解决步骤

1. 壳：截全屏 → 拖拽框选确认 → ROI；支持重框。
2. （可选）流水线自动找绿；与壳入口分离。
