# 圈定范围（Locate）

## 目标

用 CV 找出张力条在屏幕上的位置，产出 mss 所需截图范围（对角 **点1、点2** → ROI）。本段不做截图、读数、点击。

## 要实现的

- 输入：屏幕画面（或等价全屏/大区域图）；可由 Capture 的主屏抓取提供，**不**因此变成持续监控截图。
- 手段：以 `matchTemplate` 为主（可与手动两点框选并存）。
- 输出：有效 ROI（点1、点2）或明确无范围；范围变更须可被下游感知（版本递增由流水线约定）。
- 无条 / 匹配过低 → 不输出有效范围（或清空），供截图段停止监控。
- 不做：mss 按 ROI 连拍、色块读数、算法决策、键鼠执行。
