# 圈定范围（Locate）

## 目标

产出 mss 所需截图范围（对角点1、点2 → ROI），并持久化；可选一并持久化 **Frame 内张力条左右界**（手动标定）与识别参考图路径约定。本段不做连拍读数、点击。

## 要实现的

- 输入：屏幕画面或用户框选。
- **调试壳主路径**：手动两点框选 → **存盘** + 发布 ROI，并**同步为 mss 截图范围**；重框只改大小/位置；**下次启动有存盘则自动载入**（有 ROI 则 Capture/Detect 常开，无监控开关）。
- **默认手框 / 手动手框**：
  - **默认**：主屏**居中、宽高各为屏幕 1/4**；无存盘时启动写入并用它持续截图识别。
  - **手动**：用户框选确认后写入；**优先级高于默认**（有手动存盘则不用默认）。
  - **恢复默认**：壳提供入口；用当前主屏重算默认框并覆盖存盘，同时清空手动条界与参考图（等同重框副作用）。
- **条界（可选）**：与 ROI 同档存盘（Frame 坐标的左右/条框）；有则识别优先用手动条界。参考图文件与 ROI 同目录约定存放，供壳右侧标记面板显示。
- **重框 / 清空 ROI**：同时清空手动条界与参考图。
- **不做自动找绿**；ROI 只由手框（手动框选 / 恢复默认 / 明确清空 / 无存盘时写入默认）变更；Detect **不得**改写 ROI（可消费已存的手动条界）。
- 输出：有效 ROI 或明确无范围；可选手动条界。
- 不做：mss 连拍、读数、决策、键鼠、吸色、流水线自动找绿。

## 解决步骤

1. 壳启动：有存盘 → 载入（手动或曾恢复的默认）；无存盘 → 主屏居中 1/4×1/4 默认框并存盘。支持拖拽重框（手动，优先）与**恢复默认**。
2. 壳条界面板：参考图上标/改手动左右界并写回与 ROI 同档；首次有漂可自动落参考图；**「刷新参考图」等待下一次鱼漂识别成功后再用该帧更新**（禁止用无漂空图）。
