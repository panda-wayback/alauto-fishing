# 执行操作（Act）

## 目标

只把算法给出的动作意图落到真机输入。本段不做识别与决策。模拟器测策略**不经过本段**。

## 要实现的

- 动作只有两种：**按下（按住）** / **松开**。
- 输入：动作意图（要按住或要松开）。
- 输出：系统级鼠标按下或松开。
- 切换约束：按下↔松开两次切换至少间隔 **0.2s**，外加约 **100ms** 随机（与模拟器策略一致：`0.2 + U(0, 0.1)` s）；未到间隔则保持当前物理按键状态。
- 无意图或感知丢失时的安全行为（例如强制松开）待拆时确认。
- 不做：截图、CV、读数、策略逻辑。
