# 执行操作（Act）

## 目标

只把算法给出的动作意图落到**系统级鼠标**按下 / 松开。本段不做识别与决策。

## 要实现的

- 身份：**执行订阅者**。只订 `ActionIntent`；按意图维持物理键态。
- 动作只有两种：**按下（按住）** / **松开**；落点为**当前光标位置**（使用者把光标放在游戏或预览里的模拟器上）。
- 意图要按住且当前未按下 → 按下；意图要松开且当前按下 → 松开。
- **按下间隔（本段独占）**：两次**程序按下**至少间隔 `press_interval`（默认 **0s**，可调范围 **0～0.3s**）。未到间隔则先不按，等间隔满后再按；**松开立刻执行**，不受间隔约束。
- 间隔经总线主题下发；**Act 订阅**该主题；调试壳拖条发布，本段收到后生效。禁止 Decide 再叠切换间隔。
- **钓鱼态才落键**：A 关时跟鱼漂 `FISHING`；A 开时**仅开钓会话 `FISHING`**（第一下停顿/按住期间与等漂期间不落键）。  
- 离开可控鼠条件 → **立刻松开**（即使此时系统左键因开钓第一下仍按下，也只清本段程序键态，不与第一下抢释放）。  
- **系统左键优先**：仅在本段**有权控鼠**时生效；系统按下且非本程序按下 → **让位**，直到系统松开后才按当前意图接管。  
- **单帧无 Pos** 仍可能保持按住意图，**不因此松手**；连续丢漂 / 离开可控鼠条件后再自由/松开。若自由态前程序正在按住 → 松开一次后进入自由态。
- 流水线停止 / 关闭本段 → 若程序正按着则松开。
- 预览/真机联调**要真实点鼠标**，须勾选启本段；**调试壳默认开启操作**；界面展示意图、键态与按下间隔，不代替本段落键。
- 不做：截图、CV、读数、策略逻辑。

## 解决步骤

1. ActWorker 订 `ActionIntent` → 系统鼠标按下/松开（当前光标）；按下受 `press_interval` 门控，松开立即。
2. ActWorker 订按下间隔主题；调试壳滑条（0～0.3s）发布，本段更新间隔。
3. 停止或 LOST 时强制松开。
4. 预览编排可启停本段；界面只展示意图与日志，不代替本段落键。
