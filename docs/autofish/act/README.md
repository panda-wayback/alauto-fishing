# 执行操作

## 目标
只把算法给出的按住 / 松开意图落成系统级鼠标按下与松开。

## 需求
- 订阅动作意图，按意图维持物理键态：要按住且未按下时按下，要松开且已按下时松开；落点为当前光标位置。
- 两次程序按下之间至少间隔「按下间隔」，默认 0 秒、可调 0～0.3 秒；未到间隔先不按，到点再按；松开立即执行，不受间隔限制。
- 按下间隔由调试壳拖条经总线下发，本段收到即生效；其它段不得再叠加间隔。
- 只在可控鼠时落键：声音开钓关闭时跟随鱼漂拉鱼态；开启时只在会话拉鱼态落键，第一下与等漂期间不落键。
- 离开可控鼠条件时立即松开本段按下的键；若此时系统左键因开钓第一下仍按着，只清本段的程序键态，不与第一下抢释放。
- 系统左键优先：本段有权控鼠期间，若左键被非本程序按下则让位，直到用户松开后再按当前意图接管。
- 单帧没有读数时可继续保持按住，不因此松手；连续丢漂或离开可控鼠条件后才松开。
- 流水线停止或关闭本段时，若程序正按着则松开。
- 真机联调要真实点鼠标须启用本段；调试壳默认开启，界面只展示意图、键态与按下间隔，不代替本段落键。

## 方案
- 落点：`src/autofish/act`，按意图控制系统鼠标按下 / 松开，接口见 [接口](../../../src/autofish/act/interface.yaml)。
- 取舍：按下间隔只放在本段而不放在算法段，使意图切换保持即时、限速只在落键处生效。
