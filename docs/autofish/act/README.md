# 执行操作（Act）

## 目标

只把算法给出的动作意图落到**系统级鼠标**按下 / 松开。本段不做识别与决策。

## 要实现的

- 身份：**执行订阅者**。只订 `ActionIntent`；按意图维持物理键态。
- 动作只有两种：**按下（按住）** / **松开**；落点为**当前光标位置**（使用者把光标放在游戏或预览里的模拟器上）。
- 意图要按住且当前未按下 → 按下；意图要松开且当前按下 → 松开。
- 感知丢失 / 流水线停止 / 无意图 → **强制松开**。
- 切换节奏以 Decide 发出的意图为准；本段**不再**叠一层 0.2s 间隔（避免双重门控）。
- 无头模拟器批量测策略**不经过本段**；预览/真机联调**要真实点鼠标**，须启本段。
- 不做：截图、CV、读数、策略逻辑。

## 解决步骤

1. ActWorker 订 `ActionIntent` → 系统鼠标按下/松开（当前光标）。
2. 停止或 LOST 时强制松开。
3. 预览编排可启停本段；界面只展示意图与日志，不代替本段落键。
