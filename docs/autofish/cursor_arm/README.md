# 光标外形（公共状态）

## 目标

读系统当前光标位图，认出鱼漂 / 鱼钩 / 其它，作为抛杆与起钩共用的公共门闩状态（不属于自动抛杆内部）。

## 要实现的

- 信号是**当前显示的光标外形**（游戏通过系统光标换皮）；**不是** mss 截游戏画面——mss 截不到系统合成的光标。
- 直接读取系统「当前光标」位图（含热点）。
- 外形三类：`bobber`（鱼漂）/ `hook`（鱼钩）/ `other`（其它或读失败）。
- **谁开谁用**：声音开钓（A）或自动抛杆（C）任一勾选即低频观察；两者都关则停观察并清外形。
- 抛杆只认 `bobber` 为「可开抛 / 可按杆」；起钩只在 `hook` 时允许点击（听声匹配不因此停）。
- 主控以**独立公共态**展示外形预览与名称（鱼漂 / 鱼钩 / 其它），不嵌在抛竿卡内；A 或 C 开时显示。
- 与张力条拉漂识别分离；不替代 ROI 识漂。
- A / C / 壳只读本能力产出的外形与帧，禁止各自再抓一套光标各判。

## 解决步骤

1. 取光标图：系统 API 取当前光标位图（macOS / Windows）；失败则本轮跳过 / 外形为其它。
2. 外形分类：先认漂；否则认钩；否则其它。
3. 认钩：内置鱼钩模板在光标位图上匹配；够像则为鱼钩。
4. 节流：A 或 C 开时循环（约 2～5 次/秒，壳侧可更快）；都关则停。
5. 对外：落点 `src/autofish/cursor_arm`；暴露当前外形、是否鱼漂、最近一帧；经编排供给抛杆、起钩与主控公共预览。
6. 鼠标移到本壳窗口上时系统光标会变成箭头——应对准游戏画面时看门闩。
