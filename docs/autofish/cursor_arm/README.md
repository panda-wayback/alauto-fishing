# 光标外形认漂 / 认钩

## 目标

读系统当前光标位图，分别认出「鱼漂」与「鱼钩」两种外形，供抛杆开抛与声音起钩做门闩。

## 要实现的

- 信号是**当前显示的光标外形**（游戏通过系统光标换皮）；**不是** mss 截游戏画面——mss 截不到系统合成的光标。
- 直接读取系统「当前光标」位图（含热点）。
- 认漂：外形是漂形则「可开抛」；鱼钩、箭头等其它外形不是可开抛。
- 认钩：外形是鱼钩（弯钩 + 浅色钩身 + 上方羽尖，对游戏鱼钩模板足够像）则为真；漂形、箭头、读失败为假。
- 主控抛竿预览仍显示这张光标位图；边框绿 / 灰表示可开抛门闩；待命阶段字写外形名（鱼漂 / 鱼钩 / 其它）。
- 认漂 / 认钩检测仅在自动抛杆（C）勾选时低频运行（同一观察者每帧先认漂再认钩）；可开抛且空闲时右键开抛；任务进行中系统右键立刻结束（不要求认出漂）；未可开抛且无任务时不抢游戏右键。
- 同一「可开抛」也是每一杆能否按下的条件：只有当前外形是鱼漂才抛钩；鱼钩等其它外形不抛。
- 认钩亦供声音开钓在按下第一下前调用；不替代张力条拉漂识别。

## 解决步骤

1. 取光标图：用系统 API 取当前光标位图（macOS `NSCursor.currentSystemCursor`，Windows `GetCursorInfo` 等）；失败则本轮跳过 / 外形为其它。
2. 外形分类：先认漂；否则认钩；否则其它。漂形即可开抛。
3. 认钩：用内置鱼钩模板在光标位图上匹配；够像则为鱼钩。
4. 节流：仅 C 开时循环；约 2～5 次/秒（壳侧可更快）。起钩按下前也可再取一帧认钩。
5. 右键门闩：可开抛且无任务 → 开始；任务中 → 结束；不可开抛不拦截。
6. 对外：暴露「可开抛」、当前外形（bobber / hook / other）与最近一帧光标图。鼠标移到本壳窗口上时系统光标会变成箭头——应对准游戏画面时看门闩。
