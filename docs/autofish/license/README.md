# 密钥激活（离线半套）

## 目标

无有效密钥则不能进壳；密钥携带可用天数，**首次激活**后从激活日起算到期。与【打包过期自毁】完全独立。

## 要实现的

### 与打包过期的关系（已确认）

| | 密钥激活 | 打包过期自毁 |
|---|---|---|
| 管什么 | 有没有权用 | 这个安装包是否到期须自毁 |
| 无密钥 | 不能进壳（须激活） | 无关 |
| 包到期 | 无关 | 提示 → 尽删 → 退出 |
| 实现 | 独立模块；启动链上先后检查，逻辑不合并 |

启动顺序：① 包到期（过期则自毁退出）→ ② 无有效 license 则激活页 → ③ 进主窗。

### 密钥（离线）

- 载荷含 `days`（正整数）及防重放用随机 `n`；经 HMAC 签名。**到期日不写进密钥**（留给激活时起算，便于日后服务端对接）。
- **生成器**：输入天数 → 输出密钥字符串（本机/发版本用；私钥式共享密钥仅生成侧与客户端验签共用，半套可接受）。
- **激活**：校验签名 → 按密钥指纹查本机首次激活记录：
  - **首次**：`activated_on` = 当天，`expire_on` = 当天 + days；写入记录。
  - **同一密钥再次输入**：沿用首次的 `activated_on` / `expire_on`，**不重新起算**（防删软件重装刷天数）。
- **持久位置**：授权与首次激活台账写在**与安装目录 / 仓库分离**的用户状态目录（不随删 `.app` / exe / 仓库 `data/` 消失）。当前有效授权另有一份可读缓存供壳展示。
- **运行**：本地日期 ≥ `expire_on` → 视为未授权，须换新密钥激活（不自毁；旧密钥再输仍沿用原到期日）。
- **后续服务器**：仍「激活日起算」；服务端记首次激活；客户端半套台账可被服务端结果替换。

### 不做（本半套）

联网校验、账号、设备绑定、吊销列表、用密钥替代打包自毁、防清用户状态目录 / 改系统日期。

失败：密钥非法/损坏 → 提示且不写；激活页可退出程序。

### 壳内展示（已确认）

- 「更多」页展示：**授权有效至** `expire_on`（日期）。
- 若本安装包有打包到期日，同块再展示一行：**本安装包到期**（无则不显示该行）。
- 主控不展示；不替代启动门禁。

## 解决步骤

1. `common/license.py`：验签、读写 license、是否有效。
2. `packaging/gen_license_key.py`：按天数生成密钥。
3. 启动：包到期检查之后加激活门禁 + 简单输入对话框。
4. docs 索引挂上本页；expire 页注明与密钥独立。
5. 「更多」页展示授权到期；有打包到期日则同块展示。
6. 授权/首次激活台账迁到用户状态目录；同密钥再激活沿用首次到期。
