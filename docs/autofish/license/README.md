# 密钥激活（离线半套）

## 目标

无有效密钥则不能进壳；密钥携带可用天数，激活后从激活日起算到期。与【打包过期自毁】完全独立。

## 要实现的

### 与打包过期的关系（已确认）

| | 密钥激活 | 打包过期自毁 |
|---|---|---|
| 管什么 | 有没有权用 | 这个安装包是否到期须自毁 |
| 无密钥 | 不能进壳（须激活） | 无关 |
| 包到期 | 无关 | 提示 → 尽删 → 退出 |
| 实现 | 独立模块；启动链上先后检查，逻辑不合并 |

启动顺序：① 包到期（过期则自毁退出）→ ② 无有效 license 则激活页 → ③ 进主窗。

### 密钥（离线）

- 载荷含 `days`（正整数）及防重放用随机 `n`；经 HMAC 签名。
- **生成器**：输入天数 → 输出密钥字符串（本机/发版本用；私钥式共享密钥仅生成侧与客户端验签共用，半套可接受）。
- **激活**：校验签名 → 写入用户目录 `license.json`（`activated_on` / `expire_on` = 激活日 + days）。
- **运行**：本地日期 ≥ `expire_on` → 视为未授权，须重新激活（不自毁）。
- **后续服务器**：只替换「如何拿到合法密钥」；客户端仍验签 + 写/读 `license.json`（可升 v2 非对称，本半套为 v1）。

### 不做（本半套）

联网校验、账号、设备绑定、吊销列表、用密钥替代打包自毁。

失败：密钥非法/损坏 → 提示且不写 license；激活页可退出程序。

## 解决步骤

1. `common/license.py`：验签、读写 license、是否有效。
2. `packaging/gen_license_key.py`：按天数生成密钥。
3. 启动：包到期检查之后加激活门禁 + 简单输入对话框。
4. docs 索引挂上本页；expire 页注明与密钥独立。
