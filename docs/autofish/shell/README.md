# 调试壳界面

## 目标
提供真机自动拉鱼的桌面界面：主控页放能力开关和精简状态，各类配置、回测与权限放在其它页面。

## 需求

### 导航与主控
- 导航为「主控 | 自动拉漂配置 | 抛杆配置 | 声音开钓配置 | 回测 | 更多」，默认打开主控。
- 主控页顶部有授权倒计时小条，按天、时、分、秒显示到授权到期时刻，每秒刷新（见[密钥激活](../license/README.md)）。
- 主控三个勾选：声音开钓（A）、自动拉漂（B）、自动抛杆（C）。B 开策略与操作；A 开开钓会话机；**C 开则抛杆模块待命**（光标旁低频认漂 + 右键开 / 停 + F8 / F9 备用），**不勾选则整模块关闭**（见[自动抛杆](../auto_cast/README.md)）。
- 主控状态区为仪表盘三卡，文案尽量短：**POS**（大号读数、阈值、会话、耗时）、**抛杆**（大号次数：待命显示配置区间，进行中显示剩/共、就绪/阶段、C 开时光标预览）、**鼠标**（意图 / 程序 / 系统三列）；底部一行弱提示；另有「浮窗」。
- **C 开时**抛杆卡显示系统光标小预览（绿框=就绪、灰=等待）；关则藏预览。
- 没有「监控」勾选：有 ROI 时截图与识别一直运行，无 ROI 时不截不识。
- 主控上不出现框选工具、条界画布、策略数轴、按下间隔、抛杆等待、权限、音频设备、长录音、回测与模板库。

### 分页面
- 自动拉漂配置：ROI 框选与画面预览、条界标记、策略阈值数轴与应用、按下间隔，以及本页日志（见[圈定范围](../locate/README.md)、[算法判定](../decide/README.md)、[执行操作](../act/README.md)）。
- **抛杆配置**：本轮抛几次为可拖区间（1～20，开局时在区间内均匀随机出本轮总次数）、满蓄秒数（按下 = 满蓄 × 比例 ± 约 0.2 秒抖动）、拉漂成功后再抛的等待区间（默认 3 秒）、开始 / 结束快捷键（F8 / F9 备用）；说明默认用右键开 / 停（须先认出光标旁水面漂）；本页日志写清第几次与本次按下秒数；标定用 `make cast-calib`（见[自动抛杆](../auto_cast/README.md)）。
- 声音开钓配置：音频设备、监听、当前模板、播放、阈值、开钓第一下的等待 / 长按 / 松开后区间（可拖数轴）、实时波形，以及本页日志。
- 回测：长录音、会话列表、模板库、波形标注与回测，以及本页日志。
- 更多：置顶、屏幕录制、控鼠等权限（见[运行权限](../../common/permissions/README.md)）；有打包到期日时显示本安装包到期日；「恢复默认」；仅源码运行时显示「写入打包默认」。

### 日志
- 各页只记本页相关日志，最新在上，不跨页转发；「更多」页不设日志区。
- 主控记：A/B/C 开关、右键或快捷键开始 / 结束与次数用尽、恢复默认、游戏开始与结束、声音触发、抛杆阶段摘要。**不**把光标认漂的可开抛 / 未认漂翻转写入状态日志（只改自动抛杆卡文案与小预览边框）。
- 自动拉漂配置记：ROI 与条界操作提示、开始与结束拉漂（读数与阈值）、策略应用。
- 抛杆配置记：第几次 / 共几次、本次按下秒数、拉漂结束后等待秒数、右键开停、次数与满蓄 / 等待 / 快捷键变更、缺标定提示；**不**刷认漂翻转。
- 声音开钓配置记：监听起停、模板切换、会话切态、命中分、第一下、冷却与拒识。
- 回测记：长录音、会话、标注、模板库与回测报告。

### 紧凑态
- 同一主窗在完整态与紧凑态之间用一个按钮来回切换，不另开窗口。
- 紧凑态为无边框小仪表盘（窗体整体半透明可调、尽量贴内容缩小）：左 POS / 抛杆 / 鼠标三行，右竖排小字阶段；底栏透明滑条与小「主界面」同行；不调参、不看日志、不动 ROI。
- 阶段包括：待机、抛杆等待、瞄准、蓄力、听声中、听到声音（短闪）、等漂、开始游戏（短闪）、拉漂、松漂、结束游戏（短闪）；只消费已有信号（含 CAST_PHASE）；蓄力优先于听声 / 拉漂。
- 完整态与紧凑态互切时保留当前左上角就地缩放，不跳到其它屏幕；无边框时拖面板主体移动窗口。
- macOS 上紧凑态抬高窗口层级并允许出现在全屏 Space；游戏独占全屏或部分反作弊仍可能盖住。
- 记住是否紧凑态；紧凑态拖动落点只用于下次启动即为紧凑态时，且须落在某块屏幕可用区内，否则就近夹紧。

### 配置持久化
- 壳内可调的配置都会持久化：A/B/C 勾选、抛杆次数区间、满蓄秒数、抛杆开始 / 结束快捷键、抛杆等待区间、音频设备（按名称匹配，找不到时退回环回或虚拟采集）、声音相似度阈值、拉漂策略两段区间、按下间隔、窗口置顶、开钓第一下三个区间、完整态窗口位置与大小、紧凑态开关与落点、浮窗透明度；变更后即写入。抛杆圆标定不进壳配置，见[抛杆圆标定](../auto_cast/cast_calibration/README.md)。
- 启动时优先用用户配置文件，没有则用随包只读的打包默认配置，再没有则用内建缺省。
- 内建缺省：A 关、B 开、C 关、抛杆次数 5～5、满蓄 1.0 秒、开始键 F8、结束键 F9、抛杆等待 3～3 秒（拉漂成功后再抛）、阈值 0.70、策略按住 70.6～74.4 / 松开 76.6～79.2、按下间隔 0、置顶开、启动为完整态、第一下等待 0.3～1.5 秒 / 长按 0.7～1.5 秒 / 松开后 0.2～0.8 秒。
- 「写入打包默认」把当前玩法相关配置写成打包默认配置，供直接打包；不写窗体位置、紧凑落点与音频设备名等机器相关项，紧凑态强制写为关。截图坐标不写入这份默认：截图默认随当前主屏计算。
- 「更多」页「恢复默认」在安装包中也有。取消确认则配置与截图范围都不变。
- 确认后，用户配置改成与没有用户配置文件时相同：有打包默认用打包默认，否则用内建缺省；紧凑态为关，窗口位置与大小、紧凑落点、音频设备名为未设置。
- 界面立刻跟上：A/B、相似度、策略区间、按下间隔、置顶、开钓第一下三段；退出紧凑态，窗口就地回到默认尺寸，不跳到其它屏幕；音频设备按未设置重新匹配环回或虚拟采集。
- 截图范围同时按当前主屏重算居中 1/4 框，清空手动条界与参考图，并立即按新范围截图（见[圈定范围](../locate/README.md)）。拉漂配置页的「恢复默认框」仍只动截图框。
- 不删除模板、长录音与回测标注，不改密钥授权，不改打包默认文件。
- 之后移动或关闭窗口，仍按原规则记下当时的窗体位置。
- A 启动恢复时先恢复勾选，再尝试监听与会话；启动失败只提示，保留勾选与已存配置，不把偏好改成关。
- 可写数据（模板、长录音、ROI、壳配置）统一放在数据目录：源码运行为仓库 `data/`；Windows 安装包为 exe 同级 `data\`，不可写时退回 `%LOCALAPPDATA%\albn-autofish\`；macOS 安装包为 `~/Library/Application Support/albn-autofish/`，不写进 `.app`；不自动迁移旧位置的数据。
- 有存盘 ROI 时启动即载入，并持续截图与识别。

### 视觉
- 柔暗仪表风格：深炭底、低饱和海青绿强调，安静不抢游戏画面；不用紫靛渐变、霓虹电竞、大圆角玻璃与 emoji 图标墙。
- 全壳使用统一色板角色（窗底、表面、描边、主字、次字、弱字、强调、成功、警告、危险），各页不散用颜色。
- 导航用分段选中态；A/B 为开关行，开为低饱和绿青、关为灰；状态区以鱼漂读数最醒目；按钮分主、次、弱三级；少用描边分组，多用小节标题与间距；日志弱底、偏等宽、字略小。
- 画面预览区（MONITOR、条界、波形）保持可读；窗口标题只写产品名。

## 方案
- 落点：`src/tools`，PySide6 实现的调试壳各页面、紧凑态与配置持久化，接口见 [接口](../../../src/tools/interface.yaml)。
- 复用：`src/autofish` 的流水线启停与总线快照，界面只订阅画面、读数与状态，不代替任何一段落键。
- 复用：`src/common` 的数据目录、运行权限与授权查询。
- 取舍：主控 A/B/C；C 关则抛杆整模块停；C 开后默认右键开 / 停，F8 / F9 备用；次数区间 / 满蓄 / 等待进「抛杆配置」；每次开局在次数区间内抽一次总次数；蓄力零识图（光标旁认漂除外且低频）。
- 取舍：状态浮窗做成同一窗口的紧凑态而不是独立工具窗，避免两个窗口状态不同步和跨屏跳动。
- 取舍：恢复默认沿用打包默认（没有则用内建缺省），截图框按当前主屏现算，不把坐标写进默认配置。
- 取舍：抛杆圆标定仍用独立小程序，不塞进调试壳主窗。

## 不做
- 「监控」开关。
- 独立的状态工具窗。
- 在调试壳内重做抛杆圆标定编辑器。
- 未认出光标旁漂时用右键强行开抛。
- 恢复默认不删除模板、长录音与回测标注，不改密钥授权，不改打包默认文件，不把截图坐标写入默认配置。
