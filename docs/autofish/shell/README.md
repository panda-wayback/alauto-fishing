# 调试壳界面（主控干净 + 分页面设置）

## 目标

真机调试壳以**干净主控**为主：日常只用打勾开关；标定、声音、权限与策略细项进入**其它页面或弹窗**，不堆在主界面。

## 要实现的

### 主控页（默认首页，保持干净）

只放：

1. **总开关（打勾）**——仅两项  
   - **自动拉漂（B）**：一键对应策略 + 操作；细调不在主控。  
   - **声音开钓（A）**：开则跑开钓会话机；关则不听声、不点第一下。  
2. **精简状态**（一两行即可）：`POS`、会话态（若 A 开）、意图/键态摘要。  
3. **日志**（主控页状态区下方，占满剩余高度）：新消息在上；灰底 + 左侧蓝条。  
4. **入口**：前往「标定 / 声音 / 更多」——**页面切换**（首选）或弹窗；禁止主控再堆可展开大面板。

**不做「监控」勾选**：有 ROI 则 Capture + Detect **一直跑**（出画面与 Pos）；无 ROI 则不截、不识。框选只改范围，不开关监控。

主控**禁止**出现：监控开关、框选工具行、条界大画布、策略数轴、按下间隔滑条、权限整块、音频设备与录模板控件。

### 分页面（或等价弹窗）

| 页 | 内容 |
|---|---|
| **标定** | ROI 框选 / 重框 / 恢复默认（只改大小与位置）；MONITOR 预览；BAR 条界与参考图 |
| **声音** | 设备、监听、标记/播放/存模板、相似度阈值、A 相关日志细节 |
| **更多** | 权限（置顶、屏幕、控鼠、音频说明）；策略数轴与应用；按下间隔；其它低频项 |

切换方式（已选定方向）：

- **优先：同窗页面切换**（顶/底导航或侧栏：`主控 | 标定 | 声音 | 更多`），主控始终最干净。  
- **允许：弹窗**打开某一设置页（效果等同离开主控）。  
- **不采用**：主控上多块默认展开的手风琴把设置塞满。

### 与能力块关系

- 主控两勾选 = 用户心智上的「B / A」。  
- Capture/Detect 随 ROI 常开，不占用主控开关位。  
- A 会话规则见 [`docs/autofish/first_click_trigger/`](../first_click_trigger/)。  
- B 细参在「更多」；A 模板与听声在「声音」。

### 默认

- 有存盘 ROI：启动即载入并持续 Capture/Detect。  
- 无 ROI：不截不识，直到用户在标定页框选。  
- 自动拉漂（B）：默认开。  
- 声音开钓（A）：默认关。

## 解决步骤

1. 主控两勾选（A/B）+ 无监控开关 + 精简状态 + 底栏日志契约写入本页（已确认）。  
2. 标定 / 声音 / 更多 分页面信息架构写入本页（已确认）。  
3. 实现：迁出旧竖滚布局，去掉监控勾选，四页导航 + A 会话态（已完成）。
