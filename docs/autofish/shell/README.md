# 调试壳界面（主控干净 + 分页面设置）

## 目标

真机调试壳以**干净主控**为主：日常只用打勾开关；自动拉漂配置、声音开钓配置、回测、权限等进入**其它页面**，不堆在主界面。

## 要实现的

### 主控页（默认首页，保持干净）

只放：

1. **总开关（打勾）**——仅两项  
   - **自动拉漂（B）**：一键对应策略 + 操作；细调在「自动拉漂配置」。  
   - **声音开钓（A）**：开则跑开钓会话机；关则不听声、不点第一下。  
2. **浮窗切换**：同一窗在完整态 / 紧凑态之间切换（紧凑态只看运行阶段）。  
3. **精简状态**（一两行即可）：`POS`、会话态（若 A 开）、意图/键态摘要。  
4. **日志分层**（各页本地日志；**最新在上**；禁止跨页转发）

   | 位置 | 记什么 | 不记什么 |
   |---|---|---|
   | **主控** | A/B 开关；**游戏开始/结束**（是否识别到鱼漂）；声音触发（相似、间隔、按住、阈值） | 开始/结束拉漂细节；ROI/条界；回测表；设备 |
   | **自动拉漂配置** | ROI/条界操作提示；**开始/结束拉漂**（pos + 配置阈值）；策略应用 | 声音命中细节；回测 |
   | **声音开钓配置** | 监听起停、模板切换、会话切态、命中分、第一下、冷却/拒识 | 长录音；回测报告；拉漂意图 |
   | **回测** | 长录音、会话、标注、模板库、回测报告 | 实时开钓；拉漂 |
   | **更多** | **不设日志区**（权限/低频项用页面提示即可） | — |

5. **入口**：导航 `主控 | 自动拉漂配置 | 声音开钓配置 | 回测 | 更多`。

**不做「监控」勾选**：有 ROI 则 Capture + Detect **一直跑**；无 ROI 则不截、不识。

主控**禁止**出现：框选工具、条界画布、策略数轴、按下间隔、权限整块、音频设备、长录音、回测、模板库。

### 分页面

| 页 | 内容 |
|---|---|
| **自动拉漂配置** | ROI 框选 / MONITOR / BAR；策略数轴与应用；按下间隔；**本页日志** |
| **声音开钓配置** | 设备、监听、当前模板、播放、阈值；**本页日志** |
| **回测** | 长录音、会话列表、模板库、波形标注与回测；**本页日志** |
| **更多** | 权限（置顶、屏幕、控鼠）；**开钓第一下**等待/长按/松开后区间（可拖数轴）；**写入打包默认**（仅源码壳；打包版不展示） |

### 配置持久化（已确认）

- **用户运行配置**：`data/shell_settings.json`（随 `data_root`；冻结包写到本机 Application Support / LOCALAPPDATA）。  
- **打包默认配置**：`assets/shell_settings.json`（随包只读资源；入库、随 PyInstaller 打进包）。  
- 启动：有用户文件则用用户文件；否则用打包默认；再否则用代码内建缺省。  
- **写入打包默认**（「更多」页，**仅源码运行展示**；打包版整块不出现）：把当前壳配置写成 `assets/shell_settings.json`，供直接打包；**不写入**窗体位置、紧凑落点、音频设备名（机器相关），紧凑态强制关。玩法相关项（A/B、阈值、策略、间隔、置顶、开钓等待/长按/松开后等）一并写入。  
- 持久化项（壳内可调配置一律可落用户文件）：  
  - **主控 A/B 勾选**（声音开钓 / 自动拉漂）；  
  - **音频设备**（按设备名匹配；找不到则退回环回/虚拟采集启发式）；  
  - 声音相似度阈值；拉漂策略两段区间；按下间隔；窗口置顶；  
  - **开钓第一下**：命中后等待区间、长按区间、**松开后停顿区间**（秒）；  
  - **完整态窗口**位置与大小；**紧凑态开关**；紧凑态拖过的落点（仅「启动已是紧凑」时用）。  
- 变更后写入用户文件。  
- 内建缺省（无任何文件时）：A **关**；B **开**；阈值 **0.70**；策略默认 U(70.6～74.4)/U(76.6～79.2)；按下间隔 0；置顶开；**启动为完整态**；第一下等待 **0.3～1.5s**、长按 **0.7～1.5s**、松开后 **0.2～0.8s**。  
- A 启动恢复：先恢复勾选偏好，再尝试监听+会话；启动失败**保留勾选与落盘**，只提示（禁止因启动失败把偏好写成关）。  
- 模板选中仍走 `audio_template/active.json`；ROI/条界仍走既有 ROI 存盘（不在本文件重复）。

### 状态浮窗（已确认）

**同一主窗**内两种显示态，用**一个按钮来回切**；不是第二个窗口。

- **完整态**：现有导航 + 各页（主控/配置/回测/更多）。  
- **紧凑态**：只显示当前阶段大字 +「上次：…」+ 切回按钮；窗体缩小置顶，便于叠在游戏上。  
- **切换手感**：完整→紧凑 = **就地缩小**（保留当前左上角，不跳到另一块屏）；紧凑→完整 = **就地放大**回先前尺寸（保留当前左上角）。禁止一切换就 `move` 到上次紧凑坐标造成跨屏割裂。  
- **macOS 叠层**：紧凑态抬高原生窗口层级，并允许加入全屏 Space；**游戏独占全屏 / 部分反作弊仍可能盖住**，此时请用无边框窗口模式或非系统全屏。  
- **切换**：主控「浮窗」→ 紧凑态；紧凑态「主界面」→ 完整态（同一按钮语义：切换显示态）。
- **持久化**：记住是否紧凑态；紧凑态拖动后的位置仅用于**下次启动已是紧凑**时落点（须落在某块屏可用区内，否则就近夹紧）。  
- **阶段**（消费已有信号，不重算）：待机 / 听声中 / 听到声音（短闪）/ 等漂 / 开始游戏（短闪）/ 拉漂 / 松漂 / 结束游戏（短闪）。  
- **禁止**：另开独立 Tool 窗；紧凑态内调参、日志列表、ROI/回测。

### 与能力块关系

- A 规则与模板库见 [`docs/autofish/first_click_trigger/`](../first_click_trigger/)。  
- B 策略与 ROI 在「自动拉漂配置」；听声在「声音开钓配置」；长录音回测在「回测」。

### 默认

- 有存盘 ROI：启动即载入并持续 Capture/Detect。  
- 玩法缺省以 `assets/shell_settings.json` 为准（可由「写入打包默认」更新）；无该文件时：B 开、A 关、阈值 0.70 等（见上「内建缺省」）。  
- 用户改过的项写在 `data/shell_settings.json`，优先于打包默认。

### 视觉（已确认：柔暗仪表）

叠窗旁路仪表：深炭底、低饱和海青绿强调；安静、不抢游戏画面。信息架构与日志分层不变，只改观感与控件层级。

- **气质**：柔暗；禁止紫靛渐变、霓虹电竞、大圆角玻璃、emoji 图标墙。  
- **色板角色**：窗底 / 表面 / 描边 / 主字 / 次字 / 弱字 / 强调（海青）/ 成功 / 警告 / 危险；全壳统一，禁止各页散色。  
- **导航**：分段选中态（底或下划线）；未选弱字；长名可略缩字号，全称可用提示。  
- **A/B**：开关行（文案 + 开/关态），开=低饱和绿/青，关=灰；禁止整行大蓝按钮。  
- **状态区**：POS 最醒目；会话/意图次级；说明最淡；靠字重与间距，少框。  
- **按钮**：主 / 次 / 幽灵（或弱）；同排不可五个长得一样。  
- **结构**：少 `GroupBox` 描边，多小节标题 + 间距；日志弱底、偏等宽、字略小。  
- **预览区**（MONITOR / BAR / 波形）：壳体暗，画面本身保持可读（可略亮底框）。  
- **窗标题**：产品名即可，不写实现栈名。
