# 抛杆圆标定

## 目标

在独立幕布上配置透视贴地环参考，只保存与分辨率无关的比例数据，供任意屏幕按鼠标位置算抛杆力度。

## 要实现的

- 独立小程序（`make cast-calib`），不截屏：窗口内是一块按主屏纵横比缩放的空白幕布。
- 幕布上画出透视贴地环与内圈参考；形态近大远小、上窄下宽。
- 用户拖动圆心到人物脚下，调俯视角度与大小，直到参考环合适。
- 保存内容全部是比例：圆心相对屏宽 / 高、基准半径相对短边、俯视角度；不存像素值。
- 同一份标定在任意分辨率下按该屏幕尺寸自适应。
- 读取顺序：用户数据目录 → 随包 assets 默认 → 代码内建缺省；打包默认随安装包分发。
- 标定小程序「保存」写用户数据；源码运行可「写入打包默认」写入 assets，供打包装进软件；冻结安装包不写 assets。
- 只生成参考数据：不操作游戏鼠标、不识别游戏画面、不抛杆。

## 解决步骤

1. 标定值对象：圆心相对屏宽 / 高、基准半径相对短边、俯视角度；全部为比例，与分辨率无关。
2. 透视投影：按俯视角把世界同心圆采样成屏幕点列（上窄下宽、上密下疏）；不用普通椭圆拟合定义参考环。
3. 换算：给定主屏尺寸，把标定映成该屏上的圆心 / 半径 / 参考环；给定鼠标主屏点，反推世界力度比例（圆心 0、环上 1、环外 >1），抛杆用时再夹到 [0,1]。
4. 存盘：用户路径与打包默认路径各一份 JSON（比例与角度）；加载按用户 → 打包默认 → 内建；旧文件缺半径比例时用内置默认。
5. 独立幕布小程序：按主屏纵横比画空白幕布与参考环，拖圆心、调俯视角与大小；「保存」写用户文件，「写入打包默认」写 assets（仅源码）；入口 `make cast-calib`；不截屏、不识图、不抛杆。
