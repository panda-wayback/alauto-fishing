# 自动抛杆

## 目标

在真机上发起有限次数自动抛杆：用标定环把鼠标位置换成力度比例，按时长蓄力松开；可用主控勾选启停整模块，默认用右键开 / 停，F8 / F9 保留备用。

## 要实现的

- 与声音开钓（A）、自动拉漂（B）独立；主控增加「自动抛杆」勾选（C）：不勾选则整模块关闭（不侦测、不响应右键 / 快捷键、不开抛杆任务）；勾选后工人待命，可用右键或快捷键点名有限次数任务；**本轮总次数在开始时**从配置区间（1～20）均匀随机一次，进行中不再改。
- 开 / 停（模块勾选开启时）：
  - **默认**：光标旁小窗低频认出水面鱼漂后进入「可开抛」；再按一次右键 → 开始本轮（等同原 F8）；任务进行中再按右键 → 结束本轮（等同原 F9）。
  - **备用**：F8 开始 / F9 结束仍可用，便于调试。
- [光标旁认漂](cursor_arm/README.md)：读**系统当前光标位图**，外形已是漂形则「可开抛」（mss 截不到光标层）；低频；不碰张力条拉漂识别。
- 不做抛向选择：鼠标当前位置即抛向；每轮按下时读一次鼠标，按[抛杆圆标定](cast_calibration/README.md)算出目标力度比例并夹到 [0,1]。
- 蓄力按[抛杆力度](power/README.md)：按下时长 = 满蓄秒数 × 目标比例 + 约 ±0.1 秒抖动；不识别红条、不订帧。
- **开抛后先短等约 1 秒再蓄力**，避免与右键开抛抢鼠标；之后各杆仍按拉漂结束 + 配置等待。
- 本杆松杆成功后，须等拉漂结束，再按配置等待（默认 3 秒）才抛下一杆；失败中止则同样等待后重试。
- 缺标定、读不到鼠标、或未认出漂就右键：不开抛（右键不代替开始）；任务已在进行时右键结束；取消 / 关模块时立即松鼠标。
- 蓄力期独占鼠标，A / B 让位；模块关闭或无任务时不影响 A / B。
- 调试壳：主控 C 勾选 + 阶段 / 剩余次数 / 是否可开抛；抛杆配置页设次数区间（1～20，开局抽样）、满蓄、等待、快捷键；日志写清第几次、按下秒数、等待秒数；标定用 `make cast-calib`。

## 解决步骤

1. [抛杆圆标定](cast_calibration/README.md)：透视贴地环；鼠标点 → 目标力度比例。
2. [抛杆力度](power/README.md)：目标比例 → 按下时长（满蓄 + 微小抖动）。
3. [光标旁认漂](cursor_arm/README.md)：光标旁小窗低频认水面漂 → 「可开抛」门闩；右键开 / 停。
4. 自动抛杆工人：开抛后约 1 秒 settle → AIM → CHARGING → 松杆；成功则等拉漂结束再等待后 AIM。
5. 调试壳：主控 C；抛杆配置页与日志；F8 / F9 备用。
