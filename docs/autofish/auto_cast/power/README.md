# 抛杆力度（按时长）

## 目标

按住抛杆后，用目标力度比例换算按下时长，到时松开；不识别红色蓄力条。

## 要实现的

- 目标比例由鼠标位置与[抛杆圆标定](../cast_calibration/README.md)算出：0 在圆心、1 在环上，环外夹到 1。
- 按下时长 = 满蓄秒数 × 目标比例，再叠加约 ±0.2 秒的微小随机抖动（仍不低于极短下限）。
- 满蓄秒数由调试壳配置；比例为 0 时尽快松开（极短下限保证能收到一次按下）。
- 蓄力期间不截力度小帧、不识红条、不要求力度小截图区。

## 解决步骤

1. 复用[抛杆圆标定](../cast_calibration/README.md)：按下瞬间的鼠标主屏点 → 目标力度比例（已夹到 [0,1]）。
2. 时长换算：base = 满蓄秒数 × 目标比例；hold = base + 均匀随机约 ±0.2 秒，再夹到极短下限以上。
3. 蓄力执行：先按下鼠标，等到 hold 到期再松开；等待可被取消 / 停止打断并立即松开。
4. 明确不做：红条图像识别、力度小截图区框选、订帧读进度；真机填充快慢靠调满蓄秒数。
