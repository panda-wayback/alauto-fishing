# 光标旁认漂开抛

## 目标

认出「当前鼠标外形已变成鱼漂」作为「可开抛」门闩；再配合右键开始 / 结束自动抛杆，免去依赖键盘。

## 要实现的

- 信号是**当前显示的光标外形**变成漂形（游戏通过系统光标换皮，或等价的当前光标图）；**不是** mss 截游戏画面——mss 截不到系统合成的光标。
- 直接读取系统「当前光标」位图（含热点）；在该小图上判定是否为漂形；命中则「可开抛」。
- 主控预览显示这张光标位图（不是光标旁水面截图）；边框绿 / 灰表示门闩。
- 检测仅在自动抛杆（C）勾选时低频运行；可开抛且空闲时右键开抛；任务进行中系统右键立刻结束（不要求认出漂）；未可开抛且无任务时不抢游戏右键。
- 同一「可开抛」也是每一杆能否按下的条件：只有当前外形是鱼漂才抛钩；鱼钩等其它外形不抛。
- 不替代张力条拉漂识别；不把假箭头画进识别输入。

## 解决步骤

1. 取光标图：用系统 API 取当前光标位图（macOS `NSCursor.currentSystemCursor`，Windows `GetCursorInfo` 等）；失败则本轮跳过。
2. 认漂：在光标位图（不透明像素）上判定漂形特征（白肚 / 红带 / 黄羽或等价模板）；命中则「可开抛」。
3. 节流：仅 C 开时循环；约 2～5 次/秒。
4. 右键门闩：可开抛且无任务 → 开始；任务中 → 结束；不可开抛不拦截。
5. 对外：暴露「可开抛」与最近一帧光标图供主控预览；关 C 停侦测。注意：鼠标移到本壳窗口上时系统光标会变成箭头，预览也会变箭头——应对准游戏画面时看门闩。
