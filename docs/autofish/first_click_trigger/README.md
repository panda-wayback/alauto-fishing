# 声音开钓与会话状态（First Click / Session）

## 目标

可选能力：用**开钓水声**自动点第一下，进入带鱼漂的界面后，再交给现有 **Pos 拉鱼**；也可关掉声音，由用户自己点第一下，程序只拉漂；也可全部关闭，纯手钓。

起鱼水声与开钓水声易混，**不能只靠音频**；必须用**开钓会话状态机**规定何时才听声、何时才点第一下、何时才允许 Pos 拉扯。

## 要实现的

### 两大块（可独立开关）

| 能力块 | 做什么 | 关了会怎样 |
|---|---|---|
| **A. 声音开钓** | 听开钓水声 → 自动点第一下 → 等到鱼漂出现 | 用户自己点第一下开钓；程序不听声、不点第一下 |
| **B. 自动拉漂** | 有有效 Pos 后，按策略按住/松开（现有 Decide + Act） | 出现鱼漂后也不自动拉，用户自己拉 |

组合用法（已确认）：

1. **A+B 全开**：听声 → 点第一下 → 出漂 → 自动拉 → 丢漂结束 → 再听下一轮。  
2. **只开 B**：用户自己点出鱼漂界面；监控到漂后自动拉；结束后等人再开下一杆。  
3. **全关（A 关 + B 关）**：不听声、不点第一下、不自动拉；人自己钓。有 ROI 时 Capture/Detect **仍持续跑**（只出画面与 Pos，不控鼠）。

约束：

- A 与 B **互不替代**：主控勾选分离；细项进分页面。界面见 [`docs/autofish/shell/`](../shell/)。  
- A **不改 ROI**、不订 `ActionIntent`；B 仍只订 Pos + 钓鱼态。  
- 仅当会话处于 `FISHING` 且 B 开启时，才允许按意图控鼠；`FIRST_CLICK` 期间 Act 不抢键。  
- **无「监控开关」**：有 ROI 则一直截图识别；框选只改范围大小。见 [`docs/autofish/shell/`](../shell/)。

### 开钓会话状态机（A 开启时）

```text
WAIT ──水声命中──► FIRST_CLICK ──按住松开完成──► WAIT_BOBBER
  ▲                                                    │
  │                         有效 Pos（出漂）─────────────┘
  │                              ▼
  │                           FISHING  ← 此后彻底交给 Pos 拉扯（B）
  │                              │
  └──── 丢漂满 1s / 出错 / 关 A ──┘
```

| 状态 | 含义 | 声音 | 第一下 | Pos 拉扯（B） |
|---|---|---|---|---|
| `WAIT` | 等待开钓水声 | **仅此态听** | 否 | 否 |
| `FIRST_CLICK` | **正在做开钓第一下**（含按下前停顿 + 按住 + 松开） | 忽略 | 是 | 否 |
| `WAIT_BOBBER` | 等鱼漂出现 | 忽略 | 否 | 否 |
| `FISHING` | 拉鱼中 | 忽略 | 否 | 是（若 B 开） |

`FIRST_CLICK` 字面即「第一下」整段，不是「点完之后」：

1. 水声在 `WAIT` 命中 → **立刻进入** `FIRST_CLICK`（此后不再听声）。  
2. 本态内：随机等 **0.2～1.5s** → 按住 **0.1～1.0s** → 松开。  
3. 松开完成 → 进入 `WAIT_BOBBER`。

时间与转换（已确认）：

| 事件 | 行为 |
|---|---|
| 水声命中 | 立刻进 `FIRST_CLICK`；本态内随机等 **0.2～1.5s** 再按住 |
| 第一下按住 | **0.1～1.0s** 均匀随机，再松开 → `WAIT_BOBBER` |
| `WAIT_BOBBER` | **3s** 内无有效 Pos → 回 `WAIT` |
| `FISHING` | **任意丢漂后满 1s**（持续无有效 Pos ≥1s）→ 回 `WAIT`（本轮结束） |
| 任一出错 | 回 `WAIT`（控鼠失败、识别异常、关闭 A 等） |

安全规则：

- **只有 `WAIT` 才允许模板命中并进入 `FIRST_CLICK`。**  
- 其它态一律忽略水声（含起鱼水声）。  
- A 关闭：不跑会话机；出漂后是否拉扯只看 B。

### 仅开 B 时（无声音会话）

- 不进入 `WAIT` 听声逻辑。  
- 用户自行点出鱼漂后：有有效 Pos 即按现有鱼漂/意图逻辑拉扯（B 开）。  
- 无漂足够久则停止拉扯（与现有安全态一致）；不自动再点第一下。

### 音频与模板（A 用）

- 设备、BlackHole、标记模板、滑动对齐匹配等：能力保留；**控件放在「声音」页**，不进主控。  
- 内置默认 `assets/audio/splash_template.npy`；用户覆盖优先。  
- 命中与切态日志：相似度、阈值、等待/按住时长、状态名。

### 失败

- A 回 `WAIT` 不得拖垮 Capture/Detect。  
- B 关时，即使会话到 `FISHING` 也不控鼠。

## 解决步骤

1. 音频输入、缓冲、模板匹配、旧独立窗、内置模板（已完成；已迁入壳「声音」页）。  
2. 开钓会话状态机 + 切态日志（已完成）。  
3. 挂接第一下：命中进 `FIRST_CLICK` → 等 0.2～1.5s → 按住 0.1～1.0s → `WAIT_BOBBER`（已完成）。  
4. 挂接出漂 / 丢漂满 1s / 3s 超时（已完成）。  
5. 与 B 衔接：仅会话 `FISHING`（或仅开 B 时的等价条件）且 B 开才允许 Act（已完成）。  
6. 壳 UI 主控两勾选（A/B）+ 分页面 → [`docs/autofish/shell/`](../shell/)（已完成）。
