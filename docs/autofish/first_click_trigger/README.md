# 声音开钓与会话状态

## 目标
听到开钓水声时自动点第一下，等鱼漂出现后再把鼠标交给自动拉漂，并用会话状态机避免起鱼水声误触发。

## 需求

### 能力组合
- 声音开钓（A）与自动拉漂（B）在主控上分开勾选，互不替代：A 负责听声、点第一下、等出漂；B 负责出漂后按住 / 松开。
- A+B 全开：听声 → 点第一下 → 出漂 → 自动拉 → 丢漂结束 → 再听下一轮。
- 只开 B：用户自己点出鱼漂界面，程序识别到鱼漂后自动拉；无漂足够久则停止拉扯，不会自动再点第一下。
- 全关：不听声、不点第一下、不自动拉；有 ROI 时截图与识别仍持续运行，只出画面与读数。
- A 不改 ROI、不读动作意图；B 关闭时即使会话进入拉鱼态也不控鼠。

### 开钓会话状态机（A 开启时）
- 四个状态：等待水声（WAIT）→ 开钓第一下（FIRST_CLICK）→ 等鱼漂（WAIT_BOBBER）→ 拉鱼（FISHING）。
- 只有在等待水声状态、且回到该状态后已过至少 3 秒冷却，才允许水声命中；其它状态一律忽略水声，包括起鱼水声。
- 水声命中后立即进入第一下：先随机等待（默认 0.3～1.5 秒），再按住（默认 0.7～1.5 秒），松开后再随机停顿（默认 0.2～0.8 秒），然后进入等鱼漂；三个区间可在调试壳「更多」页配置并持久化。
- 等鱼漂 3 秒内没有有效读数则回到等待水声；出现有效读数则进入拉鱼，此后交给自动拉漂。
- 拉鱼中持续无有效读数满 1 秒，本轮结束，回到等待水声。
- 控鼠失败、识别异常、关闭 A 等任一出错都回到等待水声，且不得拖垮截图与识别。
- 控鼠互斥：A 开启时第一下独占鼠标，只有会话进入拉鱼态后，算法才可发按住、执行才可落键；其余状态都须松手。
- 水声命中进入第一下时，会话事件带相似分、等待 / 长按 / 松开后时长与阈值，主控据此写日志；其它切态只带简短原因说明。

### 音频输入
- macOS 选 BlackHole 等虚拟输入设备；Windows 枚举系统环回采集，选能录到游戏声的扬声器项，不选麦克风。
- 试听走本机扬声器或耳机。

### 模板库
- 用户模板库可在应用内增删、改名；内置模板库只读，同样在应用内列表展示。
- 选中的模板同时用于实时开钓与回测；不用系统文件夹对话框选模板。
- 内置默认模板按平台选择，缺失时取内置库中第一个。
- 安装包自带种子模板与种子录音会话：首次运行或用户目录缺少时拷入用户数据目录，不覆盖用户已有的同名文件，也不改用户当前选中的模板。

### 匹配
- 默认相似度阈值 0.70，静音门限默认 -80dB；除过阈值外，分数还须相对近期基线突然抬升（默认至少 0.08）才触发。
- 只有在等待水声且冷却已过时才更新抬升基线；每次进入听声时基线归零；静音时基线持续衰减。
- 实时与回测使用同一套归一化与相似度算法，结果可对照。

### 实时波形
- 开始监听后，开钓配置页展示最近约 20 秒的滚动波形，命中处标橙色区间（宽度约等于模板时长）。

### 长录音回测
- 在「回测」页启停长录音；录音会话保存在固定的数据目录下，在应用内列表中选择与删除，不打开系统文件夹。
- 可在波形上拖选区间、标注水花（绿色），并用当前模板整段回测；命中以橙色区间画在波形上，右端为命中时刻，显示区间内的峰值相似度。
- 命中时刻相差不足 0.5 秒的重复触发合并为一条，只保留最高分。
- 选区可「另存为」新模板入库。
- 回测使用独立匹配器，不影响实时监听状态。

## 方案
- 落点：`src/autofish/first_click_trigger`，负责音频采集、模板匹配、开钓会话机与模板库管理，接口见 [接口](../../../src/autofish/first_click_trigger/interface.yaml)。
- 落点：`src/tools`，提供声音开钓配置页、回测页与「更多」页的第一下区间配置，见[调试壳界面](../shell/README.md)。
- 取舍：用会话状态机限定何时听声，而不是只靠音频区分，因为起鱼水声与开钓水声很难单靠声音分开。
- 取舍：在 Mel 频谱图上做滑动归一化互相关来找短模板，入 Mel 前按短时峰值的约 95% 分位归一化，以抵抗单个杂音尖峰。
- 取舍：实时匹配只用短窗（模板长 + 0.8 秒）与长窗（模板长 + 2.0 秒）两个窗口取较高分，不沿缓冲多起点滑扫，避免抬高环境基线导致漏识别。

## 不做
- 用系统文件夹选择会话或模板。
- 「我听到水花了」手动触发按钮、按能量自动标记水花声、只靠起止秒点选标注。
