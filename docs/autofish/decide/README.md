# 算法判定

## 目标
只根据鱼漂读数和阈值策略决定下一步按住还是松开，并发布动作意图。

## 需求
- 订阅鱼漂读数、鱼漂状态与开钓会话状态，发布按住 / 松开意图。
- 阈值规则与模拟器侧策略同型（见[算法测试分包](../../simulator/algo-test/README.md)）：pos 低于当前按住阈值 low 时按住，高于当前松开阈值 high 时松开，介于两者之间保持当前意图。
- low 与 high 每次从可配置区间中均匀抽取，默认 low 取 70.6～74.4、high 取 76.6～79.2；每次意图切换成功后立即重抽，策略启动或重置时也先抽一组。
- 阈值区间由调试壳或配置注入，本段只在区间内抽样，不越界修改区间；调试壳可改四个端点并显示当前抽到的 low / high。
- 意图切换立即发出，本段不加按下间隔；间隔只由[执行操作](../act/README.md)控制。
- 声音开钓关闭时，只在鱼漂处于拉鱼态时按阈值出意图。
- 声音开钓开启时，只有会话处于拉鱼态才允许发按住；等待听声、第一下、等漂期间须发松开或保持松开，把鼠标留给开钓第一下。
- 单帧没有读数时，只要仍处在可拉漂条件下就保持上一意图，不因闪断立即松开。
- 离开可拉漂条件（鱼漂离开拉鱼态，或声音开钓开启且会话离开拉鱼态）时发松开并重置策略。
- 调试壳默认开启本段。

## 方案
- 落点：`src/autofish/decide`，按读数与阈值策略发布按住 / 松开意图，接口见 [接口](../../../src/autofish/decide/interface.yaml)。
- 取舍：阈值每次切换后在区间内随机重抽，而不是固定两个值，让按键节奏更接近人手。

## 不做
- 截图、识别与键鼠落点。
- 按下间隔。
