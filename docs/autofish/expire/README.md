# 打包过期自毁

## 目标

发放的调试壳到达指定日期后，打开即提示并退出，并尽量删除本机安装目录（尽力而为）。

## 要实现的

- **构建参数** `ALBN_EXPIRE_DAYS`：正整数天数（如 `30` = 构建当日 + 30 天到期）；空 / 不设 = 不过期。
- **CI**：`workflow_dispatch` 可填该天数；写入包内只读 `assets/expire.json`（含 `expire_on` 日历日）。
- **启动**：进主窗前用**本机本地日期**比对；已到期 → 提示「已过期」→ 尽力删除安装目录（macOS `.app` / Windows onedir）→ 退出。
- **源码运行**：无 `expire.json` 则不过期。
- **不做**：联网校时、服务端鉴权、防改时钟；不保证删文件一定成功。
- **与密钥激活独立**：无密钥不能用 ≠ 包到期自毁；两套检查、两套逻辑，互不替代。见 [`docs/autofish/license/`](../license/)。

失败：删目录失败仍须退出进程，禁止继续进壳。

## 解决步骤

1. 构建脚本按 `ALBN_EXPIRE_DAYS` 生成 `assets/expire.json`（仅打包用，不入库）。
2. 启动入口读取并校验；过期则提示、尽删、退出。
3. Release workflow 增加 `expire_days` 输入并传入双端构建。
