# 打包过期自毁

## 目标
发放的安装包到达构建时指定的到期日后，打开即提示过期、尽量删除本机安装目录并退出。

## 需求
- 构建时可填写有效天数（正整数，如 30 表示构建当日起 30 天后到期）；不填则该包不过期。
- 发版工作流可手动填写该天数，并对 macOS 与 Windows 两端同时生效。
- 启动时在进入主窗之前，用本机本地日期判断是否到期；到期则提示「已过期」，尽力删除安装目录（macOS 的 `.app`、Windows 的程序目录），然后退出。
- 删除失败也必须退出，不得继续进入调试壳。
- 源码运行没有到期信息，不过期。
- 调试壳「更多」页可只读展示本安装包的到期日（若有）。
- 与[密钥激活](../license/README.md)完全独立：启动时先检查包到期，再检查授权；两套逻辑互不替代。

## 方案
- 落点：`src/common`，提供到期判断与尽力删除安装目录，接口见 [接口](../../../src/common/interface.yaml)。
- 落点：`packaging`，构建时按天数写入包内只读的到期信息，接口见 [接口](../../../packaging/interface.yaml)。
- 取舍：只用本机日期离线判断，不联网校时，换取实现简单、无需服务端。

## 不做
- 联网校时、服务端鉴权、防修改系统时钟。
- 保证删除一定成功。
