# 锚漂识别器（bobber_anchor）

## 目标

提供 **默认** `bobber_anchor` 识别器：按阶段 **先准确定漂 → 再定/锁条界 → 有条界后只在条内跟漂算 pos**；支持手动条界覆盖程序；**有漂无条时仍报告漂位**（不算 pos），供壳展示与手动标界；`color_blocks` 仍可切换对比。

## 要实现的

- 本方法资源统一放在 `assets/bobber_anchor/`，禁止与根目录其它模板混放。
  - 漂：见 [docs/autofish/detect/find_bobber.md](find_bobber.md)
  - 左/右端帽：`endcap_*_full.png`（短帽仅备选）
- **阶段顺序（固定）**：
  1. **找漂要准**（find_bobber；宁可 miss 不可错）；
  2. **有漂后定条界**：自动端帽，或壳上手动标记；条界锁定后 UI 左右固定；
  3. **条界已固定**：找漂 **只在条左右之间（含上下容差邻域）** 进行；漂质心须同时落在条的 X 与 Y 容差内，否则本帧无读数。
- **条界来源（优先级）**：手动条界 > 程序锁定 > 未锁定时端帽定界（成功则写入程序锁）。
- 有手动或程序锁时：**禁止再跑端帽**；只条内找漂 + 算 pos。
- **有漂无条**（未锁定且端帽失败）：仍返回漂位命中（无条框、`pos` 不参与策略）；禁止假装有条。壳须能区分「无漂」与「有漂无条」。
- 漂未命中 → `None`；有条时漂出条（含纵向）→ 本帧无读数；不因 miss 自动清锁或手动界。
- **锁定 / 手动作废**：ROI 变更 / 清空 / 重框 → 丢弃程序锁与手动界（及参考图）。监控重启：程序锁清、手动存盘再载入。
- 端帽不得救起假漂；由内向外近邻取端。
- **默认识别器**；输入 RGB → 全量命中 / 仅漂命中 / `None`。
- **帧率**：≥20fps；单帧 <50ms 宜 <40ms；条内跟漂应明显快于「全图漂+端帽」。

## 解决步骤

1. 若有手动或程序锁条界：在条带邻域调用 find_bobber（尺度提示优先用上一帧，否则用**条高**估，禁止用邻域高）；命中且 XY 落在条容差内 → 用该条框算 pos。
2. 否则：全图（去边）find_bobber；无漂则 `None`。
3. 未锁定：端帽定界；成功则写入程序锁并算 pos；**失败则返回仅漂命中**（供监控画漂、条界面板出参考图，便于手动标界）。
4. `find_bar`：仅全量命中时返回条框。
5. Detect 工人：仅漂命中时 `Pos.pos=None`（策略不动作），`hit` 仍带漂坐标。
6. 壳：MONITOR 有漂即画漂点；有条再画条框；有漂即刷新条界参考图。
7. 验收：有漂无条可见漂点；标手动界后出 pos；基线与干扰帧回归不坏。
