# 找漂

## 目标
在给定搜区内只定位鱼漂的完整外形，不定条、不算 pos，宁可无结果也不错识。

## 需求
- 输入 RGB 图与可选搜区：调用方有条界时传入条带邻域，否则在整图（去边）内找。
- 输出鱼漂中心、包围盒与形状分，或无结果；坐标相对调用方原图，不含条框与 pos。
- 入图超过 800×800 时等比缩小后识别（不放大），搜区随之缩放，结果映回原图。
- 宁可无结果也不错识：候选不足、缺羽冠、结构不像或复核分不够、不够确信时一律无结果；角色皮肤、白布、技能栏不得被识成鱼漂。
- 有条带搜区时只在该邻域内找，不扫条外的人物与技能栏；邻域约定为底贴条底、只向上留羽冠容差，与[锚漂识别器](../bobber_anchor/README.md)一致。
- 鱼漂尺度大约在模板的 0.14～1.0 倍之间都能识别；首次命中后锁定尺度档，后续帧优先使用并命中即停。
- 单帧硬上限低于 100ms，有条带搜区时更快；与锚漂识别器组合后整体不低于 20fps。
- 可单独验收：有基线数据集回归，人物与技能栏干扰帧应无结果，有条界时只在条内命中。

## 方案
- 落点：`src/autofish/detect`，作为锚漂识别器内部调用的定漂能力，接口见 [接口](../../../../src/autofish/detect/interface.yaml)。
- 取舍：主路径用颜色结构（上橘羽、中红箍、下亮肚的竖向关系）挖少量候选，再用彩色小模板复核，不做整图多尺度模板扫描，以兼顾速度与抗干扰。
- 取舍：模板资源保持完整清晰，不靠缩小模板文件适配小图，小图靠尺度档处理。

## 不做
- 定条、算 pos。
- 作为可单独切换的整链路识别方法。
