# 找漂（find_bobber）

## 目标

提供独立的 **CV 找漂**：在搜区内只定位鱼漂（完整外形），不定条、不算 pos。供 `bobber_anchor` 先漂后条 / 条内跟漂调用，也可单独验收。

## 要实现的

- 输入：RGB 图；可选 **搜区**（有条界时由调用方传入条带邻域，否则整图去边）。
- **入图尺寸**：识别前若超出 **800×800**，等比缩小使宽≤800 且高≤800（不放大）；搜区随图缩放；命中坐标映回原图像素。已在限内则不改。
- 输出：漂命中（中心、包围盒、形状分）或 `None`；**不含条框、不含 pos**（坐标相对调用方入图原尺寸）。
- **主路径不是全图多尺度模板扫**，而是：
  1. **颜色结构**挖出少量「像漂」的候选（须同时体现 **上橘羽 / 中红箍 / 下亮肚** 竖向关系）；
  2. 对候选做 **小范围彩色模板复核**（完整漂图 + 透明底掩膜）。
- 人眼认漂靠色块关系；模板只作确认，禁止再当唯一主搜。
- 资源：`assets/bobber_anchor/bobber.png`（与锚漂方法共用漂图；本能力不加载端帽）。模板资产保持完整清晰；**禁止**靠把模板文件存成很小来「适配小图」。
- **尺度**：模板复核档约 **0.14～1.0**；种子估尺度后多试邻近档（估偏仍能扫到）；**首次命中后锁定该档**，后续优先用锁定档（可带 scale_hint / 条高提示覆盖）。**有锁定档时**：条邻域匹配只试邻近少档，**命中即停**（禁止扫满所有邻近档）。禁止为小图再开全图密扫。
- **宁可无读数，不可错识**：候选不足、缺羽冠、结构不够、复核分不够、单峰不够确信 → 必须 `None`；禁止把角色皮肤/白布、技能栏当漂。
- 失败：无足够确信的命中 → `None`。
- 有条界搜区时：只在该邻域内挖候选与复核，坐标映回全图；禁止再扫条外人物/技能栏。调用方条邻域约定：**底贴条底、仅向上留羽冠容差**（与 bobber_anchor 一致）。
- 单帧目标：硬上限 **< 100 ms**；有条界搜区时应更快。与 `bobber_anchor` 组合整段 ≥20fps。
- 由 `bobber_anchor` 组合调用；不单独挂 `use_*` 全链路切换。

## 解决步骤

1. 构造时加载并缓存漂模板（RGB + alpha）；禁止每帧读盘。
2. 入图超出 800×800 则等比缩小；确定搜区（有调用方条带邻域则用之并随缩放，否则整图去边）。
3. **颜色结构**在搜区内挖少量候选（上橘 / 中红 / 下亮）；小图门槛仍能抓细红箍。
4. 对每个候选：红箍宽还原整漂尺度，**多档邻近**小 ROI 彩色复核；无峰则再扩一圈档位。有锁定档或 scale_hint 时优先其邻近档。**有条邻域时**：邻域内按提示/条高/锁定档模板匹配（仍须过接受门槛）；**已锁档则少档且命中即停**。
5. **接受门槛**（缺一不可）：羽冠够、白肚/红箍结构像漂、彩色复核分够、相对其它候选有差距或单峰足够高；否则 `None`。
6. 通过则返回漂中心与包围盒（**原图**坐标），并**锁定本次命中档**供后续帧。
7. 验收：`data/test/find_bobber_baseline.json` + `check_find_bobber_baseline`；另回归：人物/技能栏干扰帧应 MISS；有条界时只在条内 HIT；含曾因估尺度偏大而 MISS 的帧应能 HIT。
8. 漂稳定后再交给 [docs/autofish/detect/bobber_anchor.md](bobber_anchor.md) 定条 / 条内跟漂。
