# 找漂（find_bobber）

## 目标

提供独立的 **CV 找漂**：在整帧 RGB 内只定位鱼漂（完整外形），不定条、不算 pos。供 `bobber_anchor` 等先漂后条流程调用，也可单独验收。

## 要实现的

- 输入：RGB 全图（与其它识别器同）。
- 输出：漂命中（中心、包围盒、形状分）或 `None`；**不含条框、不含 pos**。
- **主路径不是全图多尺度模板扫**，而是：
  1. **颜色结构**挖出少量「像漂」的候选（羽冠橘 / 红箍 / 白肚的竖向关系）；
  2. 对候选做 **小范围彩色模板复核**（完整漂图 + 透明底掩膜）。
- 人眼认漂靠色块关系；模板只作确认，禁止再当唯一主搜。
- 资源：`assets/bobber_anchor/bobber.png`（与锚漂方法共用漂图；本能力不加载端帽）。模板资产保持完整清晰；**禁止**靠把模板文件存成很小来「适配小图」。
- **尺度**：复核须覆盖手框/小分辨率下偏小的漂（约模板 0.15～0.20 起）至常见中大档；按候选估尺度只跑邻近少档，禁止为小图再开全图密扫。同图缩小后仍应能命中（在可辨识前提下），不得绑死在单一像素档。
- **宁可无读数，不可错识**：候选不足、结构不够、复核分不够 → 必须 `None`，禁止凑假漂。
- 失败：无足够确信的命中 → `None`（调用方不得假装有漂）。
- 可去掉画面边缘再搜（漂不贴边）；禁止为加速整图糊成过小分辨率导致漂外形糊掉。
- 单帧目标：**明显快于原全图多尺度模板路径**；硬上限 **< 100 ms**（候选少 + 局部复核；禁止全图全分辨率多尺度扫）。与 `bobber_anchor` 组合时整段仍须满足 ≥20fps。
- 由 `bobber_anchor`（默认识别器）组合调用；不单独挂 `use_*` 全链路切换。

## 解决步骤

1. 构造时加载并缓存漂模板（RGB + alpha）；禁止每帧读盘。
2. （可选）去掉边缘留白后再搜。
3. **颜色结构**在搜区内挖少量候选框（须体现上橘 / 中红 / 下亮一类竖向关系）；小分辨率下连通域/形态学门槛须仍能抓住细红箍；候选过多则收紧或截断，禁止变回全图密扫。
4. 对每个候选：用红箍宽还原整漂尺度，取邻近少档做 **小 ROI 彩色模板复核**（尺度下限须覆盖小图；ROI 须装得下估尺度模板）；取通过门槛的最优者。
5. **接受门槛**（缺一不可）：结构像漂、彩色复核分够、相对其它候选有足够差距；否则 `None`。
6. 通过则返回漂中心与包围盒。
7. 用 `data/test` **只标漂**验收；正确基线：`data/test/find_bobber_baseline.json` + `check_find_bobber_baseline`。另须回归：同图缩小 / 典型手框尺寸仍能 HIT（不错识变差、耗时不显著变差）。
8. 漂稳定后再交给 [docs/autofish/detect/bobber_anchor.md](bobber_anchor.md) 定条。
