# 识别

## 目标
从手框画面中找出绿条与鱼漂，算出鱼漂在条内的位置（0～100）并发布读数。

## 需求
- 订阅当前 ROI 与最新帧；没有帧时等待，与当前 ROI 版本不一致的帧直接丢弃。
- 只认最新帧：积压的帧不识别；已开始识别的帧算完仍发布读数。
- 对外给出三件事：绿条位置、鱼漂位置，以及由两者算出的 pos（0～100）。
- 识别到鱼漂但没有条界时，读数仍带鱼漂位置但 pos 为空，调试壳可区分「无漂」与「有漂无条」，策略不据此动作。
- 每帧识别耗时随读数一起发布，供日志与界面显示效率。
- 单帧识别异常不得让识别线程退出；监控重启时重置帧序，不能出现中断后永久不识别。
- 不发布、不缩小、不改写当前 ROI；可读取圈定范围中存的手动条界。

## 方案
- 子功能：[锚漂识别器](bobber_anchor/README.md)，默认且唯一的识别方法，先定漂、再定条、再在条内跟漂算 pos。
- 子功能：[找漂](find_bobber/README.md)，只定位鱼漂的独立 CV 能力，由锚漂识别器调用。
- 落点：`src/autofish/detect`，从帧识别绿条与鱼漂并发布读数，接口见 [接口](../../../src/autofish/detect/interface.yaml)。
- 取舍：只保留锚漂一种识别方法，不保留色块、模板等备用识别器，以减少切换与维护成本。

## 不做
- 改截图范围、手框界面、吸色定框与键鼠。
- 色块（color_blocks）、整图模板等备用识别器。
