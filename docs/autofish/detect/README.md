# 识别（Detect）

## 目标

订 ROI 与最新 Frame，在手框画面内读出鱼漂 **0～100**。本段不做手框存盘、不改 mss 范围、不做键鼠。

## 要实现的

- 输入：订阅 **ROI** + **最新 Frame**（Frame 已是手框截取结果）；无 Frame 则等待；错 `roi_version` 丢弃。
- **只认最新帧**：积压/历史 Frame **一律抛弃**；识别算完时若已有更新 Frame，**本帧 Pos 不发布**。
- **mss 范围只由手框决定**；Detect **禁止**发布/缩小/改写当前 ROI。
- **张力条特征（必须同时满足）**：
  - **左橘红/橘黄 | 中绿 | 右橘红/橘黄**（色块均匀、长条）；无双侧橘端 → **不认条**
  - **橘端贴在绿段左右外侧**（不在整帧左右边沿盲找）；橘端与绿段**垂直厚度基本一样**
  - 绿段用水平闭运算连成扁长连通域后再验；禁止用「整段绿列」冒充左右界；禁止整段橙当 0/100
  - 条须明显扁长（宽 ≫ 高）；过高绿带（草地等）舍弃
- **0～100**：在认定的绿段左右各外扩绿宽×5%，裁进当前帧；带内找鱼漂：
  - 优先绿掩膜内孔（漂挡住绿）；否则乳白质心
- 无漂 → 无读数（仍可携本帧供监控）。
- 不做：改 mss、手框 UI、吸色、模板定框、键鼠。

## 解决步骤

1. 订 Frame（及 ROI 版本校验）。
2. 色块找「橘|绿|橘」扁长条（绿闭运算轮廓 + 邻接橘端同高）→ 绿±5% → 带内孔/白 → Pos。
