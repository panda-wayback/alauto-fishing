# 识别（Detect）

## 目标

不断消费截图段产生的**最新**画面，在张力条上读出鱼漂 **0～100**。本段不做圈 ROI、截图、决策、点击。

## 要实现的

- 输入：最新 Frame（ROI = 手框监控范围；CV 不得越出该框）。
- **0～100 区间**：先取完整**绿条**左右端，再各向外扩 **绿条宽度的 5%**（略含两侧近端橘色）；扩后仍须裁在 ROI 内。
- 禁止：用整段橙端当 0/100（橙区会虚占读数）；禁止只用被鱼漂挖断的单块绿。
- 手段：在上述区间内找白色鱼漂中心 → 映射 0～100。不做模板、吸色。
- 无白 → 无读数。
- 不做：圈定、mss、按住/松开、键鼠。

## 解决步骤

1. 在 ROI 内得到完整绿条左右端（桥接鱼漂空洞），高度取绿带。
2. 左右各加绿宽×5%，裁进 ROI → 作为 0 与 100。
3. 该区间内找白质心映射读数；无白则无读数（可携本帧）。
