# 锚漂识别器

## 目标
作为默认识别方法，先准确找到鱼漂，再定位并锁定张力条左右界，之后只在条内跟漂算出 pos。

## 需求
- 阶段顺序固定：先用[找漂](../find_bobber/README.md)准确定漂（宁可漏识不可错识）；有漂后再定条界；条界固定后只在条内跟漂。
- 条界来源优先级：手动条界 > 程序锁定的条界 > 未锁定时按条两端端帽自动定界（成功则写入程序锁）。
- 已有手动或程序锁定的条界时，不再做端帽定界，只在条内找漂并算 pos。
- 条内找漂的搜区底边贴条底、只向上留出羽冠容差；鱼漂中心须同时落在条的横向与纵向容差内，否则本帧无读数。
- 有漂无条（未锁定且端帽定界失败）时仍返回鱼漂位置，不给条框、pos 不参与策略，不假装有条，便于用户在调试壳上手动标界。
- 鱼漂未命中时本帧无读数；单帧未命中不清除程序锁或手动条界。
- ROI 变更、清空或重框时，丢弃程序锁、手动条界与参考图；仅开关监控而 ROI 未变时保留程序锁与跟漂状态，手动条界仍从存盘载入。
- 端帽定界不得把假漂救成有效读数。
- 入图超过 800×800 时等比缩小后识别，结果坐标映回原图。
- 整体帧率不低于 20fps，单帧低于 50ms、宜低于 40ms；条锁定后跟漂明显快于整图找漂加端帽，不出现数百毫秒的耗时尖峰。

## 方案
- 落点：`src/autofish/detect`，作为默认识别方法对外提供，接口见 [接口](../../../../src/autofish/detect/interface.yaml)。
- 复用：[找漂](../find_bobber/README.md) 的定漂能力，本识别器只负责条界与 pos。
- 取舍：先漂后条而不是先条后漂，因为鱼漂特征更可靠，端帽定界在无漂时容易误判。
- 取舍：条锁定后每帧只扫中等窗，丢失后隔帧扫整个条邻域，不在同帧做两次扫描，以避免重新上漂时的耗时尖峰。

## 不做
- 自动清除用户手动标的条界。
