# 截图（Capture）

## 目标

mss **只**负责按**当前 ROI（=手框）**持续出帧。本段不做找条、读数、决策、点击。

## 要实现的

- 订/读当前 ROI：有有效 ROI → 按该范围持续截图，发布 Frame；**帧宽高 = ROI 逻辑尺寸**（Retina 缩回点）。
- **无 ROI → 不截图、不持续监控。**
- 手框确认后立刻成为当前 ROI；**范围只随手框/清空变更**，不被 Detect 改写。
- 可对外提供主屏/全屏一帧供 Locate 找条（一次性，非本段连拍）。
- ROI 版本变更后旧帧作废。
- 不做：模板找条、色块识别、算法、键鼠。

## 解决步骤

1. 按总线当前 ROI 截帧；无 ROI 空转。
2. 帧尺寸对齐当前 ROI 逻辑宽高。
