# 截图

## 目标
只按当前 ROI（即手框）持续截屏并发布帧。

## 需求
- 有有效 ROI 时持续截图并发布帧；无 ROI 时不截图、不持续监控。
- 手框确认后立即成为当前 ROI；截图范围只随手框或清空变化，不受识别段影响。
- ROI 用逻辑点表示，帧保留物理像素：帧宽高等于 ROI 逻辑尺寸乘以主屏缩放倍率，不缩回逻辑点，避免系统缩放大于 100% 时丢像素。
- 对外提供主屏缩放倍率，供调用方在帧坐标与逻辑点之间换算。
- 可按需提供一次主屏整屏帧，供圈定范围使用；这不属于持续截图。
- ROI 版本变更后，旧帧作废。

## 方案
- 落点：`src/autofish/capture`，按 ROI 截屏并发布帧，接口见 [接口](../../../src/autofish/capture/interface.yaml)。
- 取舍：帧保留物理像素而不缩放到逻辑尺寸，以换取高缩放屏幕上的识别精度。

## 不做
- 找条、色块识别、读数、决策与键鼠。
