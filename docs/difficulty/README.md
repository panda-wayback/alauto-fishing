# 拉鱼难度（鱼等级）

## 目标

按 Albion 鱼等级分档：越高越难；须靠短按短松在进度走完前避开左右红区。

## 要实现的

- 开局可选 **T1–T8**；默认 T4。
- 只影响拉鱼段；不引入鱼竿/饵/专精。
- 设计对齐：左=鱼挣扎，右=人收线；**须高频点按**；长按冲右红、松太久掉左红；进度到头前碰红即失败。
- 等级升高时同时更难：
  1. 鱼向左拉力更强、波动更大更快（更难预判）。
  2. 进度更慢；向左时倒退更多。
  3. 靠右才好涨进度，逼近右红区操作。
  4. 速度更快，容错更小。
  5. 玩家向右力上限不随等级抬高（禁止高档长按碾平）。
- 不靠缩小绿区制造难度。
- 不做：稀有鱼单独档、假咬、装备加成。

## 解决步骤

1. T1–T8 相对 T4 的参数曲线（单调加难）→ 已接入，按真机手感持续校正。
2. 开局数字键选档 → 已完成。
3. 对局套用该档参数 → 已完成。
