# src/tools/ 功能说明

更新时间：2026-09-20

## 本文件夹职责

调试壳（**PySide6**）：订阅总线展示；**监控 / 策略 / 操作** 勾选启停。右侧条界标记面板。无快捷键。

## 目录清单

- `preview_app.py` — 调试壳 UI
- `bar_mark_canvas.py` — 条界参考图 + 程序/手动竖线（手动可拖）
- `dual_range_axis.py` — 策略双区间数轴（拖动；不重叠；间隔≥1；精度 0.1）

## 对外契约

- `PreviewApp`（QMainWindow）
- 感知：POS + 监控勾选 + 截屏/框选按钮
- 权限：顶栏「置顶」（默认开，`WindowStaysOnTopHint`）+ 授权/测试/提权重启；macOS 另有「清理授权」（`reset_macos_tcc`；约 2s 刷新）
- 策略：启用勾选（**默认开**）+ 数轴默认按住 U(70.6～74.4)/松开 U(76.6～79.2)；切换成功后重抽；实时「要按住/要松开」+ 当前 low/high
- 操作：启用勾选（**默认开**）；按下间隔滑条 0～0.3s（默认 0.02，发 `PRESS_INTERVAL`）；系统左键优先；`FISHING` 才控鼠；非钓鱼态 = 自由态
- 截屏：直接抓主屏（不挪窗、不最小化）
- 确认框选 → 存盘 + `set_roi_manual` + **自动开监控**；框选前停监控；重框清空手动条界与参考图
- **有存盘 ROI 时启动即载入手框/条界/参考图，并自动开监控**（策略/操作仍默认开）
- 监控原画面；叠层：有漂画漂点（有漂无条亦画），有条再画条框；预览 UI ≤15fps
- 右侧 BAR：有漂即存/显参考图；蓝=程序界、黄=手动界（拖左右边，覆盖程序）；「清除我的标记」；与 `roi.json` 同档存 `bar_*`，参考图 `bar_ref.png`
- POS 显示：无漂 / **有漂·无条** / 数值；仅有条时策略用 pos
- 识别耗时：实时输出行右侧显示当前帧 ms；每 2s 日志一条

## 约束

- 允许依赖 `autofish` / PySide6；壳内**不再嵌模拟器**。
- 禁止实现五段业务。
