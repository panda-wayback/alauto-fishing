# src/tools/ 功能说明

更新时间：2026-09-17

## 本文件夹职责

调试壳（**PySide6**）：订阅总线展示；**监控 / 策略 / 操作** 勾选启停。模拟器嵌窗手玩，不跟 Act。无快捷键。

## 目录清单

- `preview_app.py` — 调试壳 UI
- `dual_range_axis.py` — 策略双区间数轴（拖动；不重叠；间隔≥5）

## 对外契约

- `PreviewApp`（QMainWindow）
- 感知：POS + 监控勾选 + 截屏/框选按钮
- 策略：启用勾选（**默认开**）+ 数轴拖两段范围（不重叠、间隔≥5）；切换成功后重抽；实时「要按住/要松开」+ 当前 low/high
- 操作：启用勾选（**默认开**）；系统左键优先；`FISHING` 才控鼠（单帧无漂不松）；非钓鱼态 = 自由态；实时「意图/程序/系统」
- 截屏：直接抓主屏（不挪窗、不最小化）
- 确认框选 → 存盘 + `set_roi_manual`；框选前停监控
- 监控原画面；叠层：Pos 范围框（绿±5%）+ 搜白框 + 命中点
- 识别耗时：实时输出行右侧显示当前帧 ms；每 2s 日志一条（均/最大/最小/≈FPS）
- 模拟器：默认无画面；点击开始才出图；成功/失败/关局关画面；与操作互不强制关闭
- 禁止把 Act 状态写入 `FishingGame`

## 约束

- 允许依赖 `autofish` / `sim` / `ui` / PySide6。
- 禁止实现五段业务；禁止壳内耦合模拟器与操作器。
- 模拟器 pygame 仅离屏渲染（`SDL_VIDEODRIVER=dummy`）。
